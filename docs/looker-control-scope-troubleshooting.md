# Looker Studio コントロール適用範囲の限定（グループ化）— 調査結果とトラブルシューティング

調査日: 2026-07-03。OSM施設マップ P1 の「自治体▼を県内比較チャートに効かせない」構築中に、
グループ化しても県内比較が1本に縮む症状が出たため、公式情報を調査した記録。

**【解決済み 2026-07-03】実際の原因は下記チェックリスト2番の「コントロールがレポートレベルに
設定されている」だった。ページレベルに戻して解消。同症状が再発したら本チェックリストで確認する。**

## 結論

**グループ化によるコントロールのスコープ限定は公式機能として存在する（2026年現在も有効）。**
公式ドキュメント（最終更新 2026-06-29）に明記: 「グループ化すると、コントロールはグループ内のグラフにのみ適用されます」
（原文: *"Once grouped, the control only affects the charts in the group."*）

**推奨手段**: コントロール＋効かせたいチャートを1つのグループにまとめ、除外したいチャートはグループ外に置く。
これが公式の定石で、代替手段（後述）より確実。

## 手順

1. レポートを編集モードで開く。
2. **Shift+クリック**（または範囲ドラッグ）でコントロールと、効かせたいチャートを**すべて同時に**選択。
   **コントロール自身を必ず選択に含めること**（最重要）。
3. メニュー **[配置] > [グループ化]**、右クリック → 配置 → グループ化、または **Ctrl+G**（Mac: Cmd+G）。
4. 確認: グループ内のどれか1つをクリックすると、グループ全体が1つの枠で選択されれば成功。
   ビューモードでプルダウンを操作し、グループ外チャートが変化しないことを確認。
5. 解除は右クリック → 配置 → グループ化解除（**Ctrl+Shift+G**）。

## 「グループ化したのに除外チャートにも効いてしまう」原因チェックリスト（優先順）

1. **コントロールがグループに入っていない（最有力）**。
   チャートだけをグループ化した場合、コントロールはページレベルのままで、ページ上の互換チャート全部に
   効き続ける。スコープが縮まるのは「コントロール自身がグループの一員になったとき」だけ。
   → コントロールを含めて選択し直して Ctrl+G。
2. **コントロールが「レポートレベル」に設定されている**。
   右クリック →「レポートレベルに設定」が有効なコントロールは全ページ・全チャートに効き、
   **グループ化の対象にもできない**（右クリックでグループ化メニューが出ない場合はこれが原因）。
   → 「ページレベルに設定」へ戻してからグループ化。
3. **同じフィールドを使う別コントロールが存在する**（重複配置・レポートレベルの別プルダウン・非表示レイヤーなど）。
   → ページとレポートレベルの全コントロールを棚卸し。
4. **クロスフィルタリングの干渉**。
   プルダウンではなく、地図や他チャートのクリック（クロスフィルタ）で除外チャートが絞られているケース。
   クロスフィルタもグループで制限されるが、発生元チャートがグループ外なら届いてしまう。
   → 除外チャートの [設定] で「グラフのインタラクション（クロスフィルタ）」をオフ、または発生元もグループへ。
5. **除外したいチャートが誤ってグループに巻き込まれている**（範囲ドラッグ選択時にありがち）。
   → 除外チャートをクリックして親にグループ枠が出ないか確認。出たらグループ解除して作り直し。
6. **編集画面の表示が古い/選択値が残っている**。→ コントロールをリセットし、ビューモードで再確認。
7. 上記で解決しない場合、症状はフィルタ以外の原因の可能性もある
   （チャート自身のチャートレベルフィルタ、ディメンション設定、行数制限、データの実態）。
   チャートを一時的に表に変えて中身を確認するのが早い。

## 代替手段（グループ化以外）

- **チャート側で「このコントロールを無視」する設定は存在しない**
  （Power BI の「相互作用の編集」に相当する機能はなし）。除外はグループ化かデータソース分離のみ。
- **別データソース化で連動を切る**: 除外チャートだけ複製した別データソースに載せる。
  ただし Looker Studio のコントロールは**フィールドIDが一致すれば別データソースのチャートにも効く**。
  同じ BigQuery テーブルから複製したデータソースはフィールドIDが一致しがちなので、確実に切るには
  カスタムクエリで列名を変える（例: `muni_name AS muni_name_all`）必要がある。手間と保守性の面で非推奨。
- **パラメータ＋計算フィールド/チャートレベルフィルタ**: プルダウンをパラメータ入力にし、
  効かせたいチャートだけに「フィールド = パラメータ値」のフィルタを付ける。
  適用範囲を完全に明示制御できる反面、選択肢リストを手動定義する必要があり、自治体一覧のような
  動的な選択肢には不向き。
- **チャートレベルフィルタでコントロールを打ち消す方法は不可**:
  チャートレベルフィルタはコントロールと AND で積み重なるだけで、コントロールを無効化できない。
