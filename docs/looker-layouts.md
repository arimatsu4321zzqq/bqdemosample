# Looker Studio 仮レイアウト案 — デモ第一弾3レポート

3データセット（thelook_ecommerce / google_trends / austin_bikeshare）で1ページずつのダッシュボードを構成。
各チャートは「Looker Studioのチャート種類 / ディメンション / 指標 / データソース」で定義。

---

## レポートA：EC売上ダッシュボード（thelook_ecommerce）

テーマ＝**業務BI（売上・顧客・商品）**。経営者に刺さる王道構成。

```
┌──────────────────────────────────────────────────────────────────┐
│  🛒 EC売上ダッシュボード      [期間▼] [カテゴリ▼] [部門▼] [国▼]   │
├───────────────┬───────────────┬───────────────┬──────────────────┤
│ 総売上        │ 注文数        │ 購入顧客数    │ 平均注文単価     │
│ $1.23M        │ 45,678        │ 12,345        │ $89.4            │
├───────────────┴───────────────┴───┬───────────┴──────────────────┤
│ 月別売上推移（時系列グラフ）       │ カテゴリ別売上（横棒グラフ） │
│   ╱╲    ╱╲   ╱                      │ Jeans  ███████               │
│  ╱  ╲__╱  ╲_╱                       │ Tops   █████                 │
│                                     │ Shoes  ████                  │
├──────────────────────┬──────────────┴──────────────────────────────┤
│ 国別売上             │ 部門構成     │ ブランド別Top10（横棒）       │
│ （地域別マップ）     │ （ドーナツ） │ Nike   ████                   │
│  [world choropleth]  │ Men45/Women55│ Levi's ███                    │
├──────────────────────┴──────────────┴───────────────────────────────┤
│ 商品別売上ランキング（テーブル）                                     │
│ 商品名 | カテゴリ | ブランド | 売上 | 注文数 | 返品率               │
└──────────────────────────────────────────────────────────────────┘
```

| # | チャート種類 | ディメンション | 指標 | 元データ |
|---|---|---|---|---|
| 1 | スコアカード×4 | — | 総売上=SUM(sale_price) / 注文数=CD(order_id) / 顧客数=CD(user_id) / 平均単価 | order_items |
| 2 | 期間（時系列）グラフ | created_at（月） | SUM(sale_price) | order_items |
| 3 | 横棒グラフ | products.category | SUM(sale_price) | order_items×products |
| 4 | 地域別マップ | users.country | SUM(sale_price) | order_items×users |
| 5 | ドーナツグラフ | products.department | SUM(sale_price) | order_items×products |
| 6 | 横棒グラフ | products.brand（Top10） | SUM(sale_price) | order_items×products |
| 7 | テーブル | products.name | 売上・注文数・返品率 | order_items×products |
| フィルタ | 期間/カテゴリ/部門/国 コントロール | | | |

> 計算フィールド例：返品率 = COUNT(returned_at) / COUNT(order_id)、粗利 = sale_price − cost

## レポートB：検索トレンド分析（google_trends）

テーマ＝**地域×時系列のトレンド**。「今どこで何が伸びているか」を見せる。

```
┌──────────────────────────────────────────────────────────────────┐
│  🔍 検索トレンド分析        [国▼] [対象週▼] [ワード検索🔎]        │
├───────────────────┬───────────────────┬──────────────────────────┤
│ 対象国数          │ ユニークワード数  │ 最新更新週               │
│ 50                │ 8,200             │ 2026-06-15               │
├───────────────────┴───────────┬───────┴──────────────────────────┤
│ 国別 人気度（地域別マップ）    │ 急上昇ワードTop15（横棒）        │
│  [world choropleth, score]     │ ◯◯  +480%  ███████               │
│                                │ △△  +350%  █████                 │
│                                │ □□  +300%  ████                  │
├────────────────────────────────┼──────────────────────────────────┤
│ 人気ワード推移（時系列）       │ 国別 人気ワードTop（テーブル）   │
│  ワードを選ぶとscoreの週次推移 │ 国 | ワード | rank | score       │
└────────────────────────────────┴──────────────────────────────────┘
```

| # | チャート種類 | ディメンション | 指標 | 元データ |
|---|---|---|---|---|
| 1 | スコアカード×3 | — | CD(country_name) / CD(term) / MAX(refresh_date) | international_top_terms |
| 2 | 地域別マップ | country_name | AVG/MAX(score) | international_top_terms |
| 3 | 横棒グラフ | term（Top15） | MAX(percent_gain) | international_top_rising_terms |
| 4 | 期間（時系列）グラフ | week | score（特定termでフィルタ） | international_top_terms |
| 5 | テーブル | country_name, term | rank, score | international_top_terms |
| フィルタ | 国/対象週/ワード検索ボックス | | | |

> 日本に寄せるなら country_code='JP' でフィルタし「日本の急上昇ワード」ページを別途追加できる。

## レポートC：シェアサイクル人流ダッシュボード（austin_bikeshare）

テーマ＝**人流・移動（ドコモ親和）**。時間帯ヒートマップと移動動線が見せ場。

```
┌──────────────────────────────────────────────────────────────────┐
│  🚲 シェアサイクル人流        [期間▼] [会員種別▼] [自転車種別▼]   │
├──────────────┬──────────────┬──────────────┬─────────────────────┤
│ 総乗車数     │ 平均乗車時間 │ 稼働ステーション│ 電動バイク比率     │
│ 1,250,000    │ 18.4 分      │ 102           │ 38%                 │
├──────────────┴──────────────┴───┬──────────┴─────────────────────┤
│ 日別乗車数推移（時系列グラフ）   │ 時間帯×曜日 ピーク（ヒートマップ）│
│   ╱╲╱╲╱╲╱╲ （季節変動）          │  月火水木金土日                  │
│                                  │ 7時 ░▓▓▓▓░░                       │
│                                  │ 8時 ▓███▓░░  ← 通勤ピーク          │
├──────────────────────┬───────────┴──────────────────────────────┤
│ ステーション分布     │ 出発ステーションTop10（横棒）             │
│ （バブルマップ）     │ Downtown   ████████                       │
│  ◯ ◯ ◯ サイズ=乗車数 │ Univ        ██████                        │
├──────────────────────┼────────────────────┬──────────────────────┤
│ 会員種別構成（円）   │ 自転車種別（円）   │ 区間Top（テーブル）  │
│ Annual/Walk Up...    │ electric/classic   │ 出発→到着 | 回数     │
└──────────────────────┴────────────────────┴──────────────────────┘
```

| # | チャート種類 | ディメンション | 指標 | 元データ |
|---|---|---|---|---|
| 1 | スコアカード×4 | — | 総乗車=COUNT / 平均=AVG(duration_minutes) / 稼働数=CD(start_station) / 電動比率 | bikeshare_trips |
| 2 | 期間（時系列）グラフ | start_time（日） | COUNT(trip_id) | bikeshare_trips |
| 3 | ピボット＋条件付き書式（ヒートマップ） | 時(HOUR) × 曜日 | COUNT(trip_id) | bikeshare_trips |
| 4 | バブルマップ（Googleマップ） | station 緯度経度 | COUNT(trip_id) | trips×stations |
| 5 | 横棒グラフ | start_station_name（Top10） | COUNT(trip_id) | bikeshare_trips |
| 6 | 円グラフ×2 | subscriber_type / bike_type | COUNT(trip_id) | bikeshare_trips |
| 7 | テーブル | 出発→到着（連結） | COUNT(trip_id) | bikeshare_trips |
| フィルタ | 期間/会員種別/自転車種別 | | | |

> 計算フィールド例：時間帯 = HOUR(start_time)、曜日 = WEEKDAY(start_time)、電動比率 = COUNTIF(bike_type='electric')/COUNT()
> stationsのlocationは文字列なので、緯度経度に分解する計算フィールドが必要。

## 試せるチャート一覧（各ページで差し替えて見比べる）
- 基本: スコアカード / 表 / ピボット表 / 折れ線(時系列) / 棒・積み上げ棒 / 円・ドーナツ
- 応用: コンボ(棒＋線) / 面グラフ / 散布図・バブル / ツリーマップ / ゲージ / ヒートマップ(ピボット＋条件付き書式)
- 地図: 地域別マップ(塗り分け) / バブルマップ / ヒートマップレイヤー(Googleマップ)
- コミュニティビジュアル: サンキー / ファネル / ワードクラウド 等（追加導入）

## 共通の作り込みポイント
- **配色・ロゴ**を統一して「自社プロダクト」感を出す（公開データ感を消す）
- 各ページに**自然言語Q&Aへの導線**（「AIに質問」ボタン/埋め込み）を置き、Conversational Analyticsと一体で見せる
- Looker StudioのデータソースはBQ直結。整形済みデモデータセット（自PJ）を指すとコスト・速度が安定
