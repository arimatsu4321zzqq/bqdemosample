# P3 全国サマリ ページ作成手順

前提: [`looker-setup-common.md`](./looker-setup-common.md) 完了。
実物イメージ: [`mock/P3.png`](./mock/P3.png)。データソースは **週次明細のみ**（コントロール不要の一番簡単なページ）。

## このページで作るもの
デモの導入で「データの規模と鮮度」を掴ませ、全国の今週を一望するページ。
KPI×4＋全国Top10＋県ごとの1位。

## 1. KPI スコアカード ×4

| チャート名 | 指標 | 集計 |
|---|---|---|
| KPI_追跡ワード数 | `term` | **COUNT_DISTINCT** |
| KPI_対象都道府県 | `region_name` | **COUNT_DISTINCT** |
| KPI_追跡週数 | `week` | **COUNT_DISTINCT** |
| KPI_最新週 | `week` | **MAX** |

> ⚠ スコアカードの既定集計は SUM。4枚とも必ず上表の集計に変える。

**期待される表示結果（2026-07時点・実測）**: **779** / **47** / **266** / **2026-06-28**
（週数・最新週はテーブル再実行で増える）。

## 2. 表_全国の今週Top10（ランクイン県数順）

| 項目 | 内容 |
|---|---|
| チャート種類 | 表（棒付き） |
| データソース | 週次明細 |
| ディメンション | `term` |
| 指標 | ①`region_name` → **COUNT_DISTINCT**（列名「ランクイン県数」・棒表示） ②`latest_rank` → **AVG**（列名「平均順位」） |
| 並べ替え | ランクイン県数 **降順** → 平均順位 **昇順** |
| 行数 | 10 |
| チャート単位フィルタ | **`is_latest_week` = true** |
| 配置 | 左下（幅約700×高さ330） |

> ⚠ 「平均スコア順」にしない（score はワード間比較不可）。
> 「47県中何県でTop25入りしたか」が検索量ベースで比較できる正しい全国指標。

**期待される表示結果（2026-06-28週・実測）**: 1位 **オランダ 対 モロッコ（47県・平均順位1.0）**。
以下、橋本愛・田中みな実・ブラジル 対 日本などが46〜47県で続く。

## 3. 表_県ごとの1位ワード

| 項目 | 内容 |
|---|---|
| チャート種類 | 表 |
| データソース | 週次明細 |
| ディメンション | `県名`, `term` |
| 指標 | なし（明細） |
| 並べ替え | `県名` 昇順 |
| チャート単位フィルタ | **`is_latest_week` = true AND `latest_rank` = 1** |
| 行数 | 15〜20＋ページング |
| 配置 | 右下（幅約600×高さ330） |

> ⚠ **1位はタイが普通**（実測: 2026-06-28週は全47県で「橋本愛」「ブラジル 対 日本」
> 「オランダ 対 モロッコ」の3語が1位タイ＝表は約140行になる）。
> 「1県=1行」にしたい場合は term の MIN を取る等の加工が要るが、タイのまま見せて
> 「今週は全国どこもこの3強」と話す方がデータに正直で、デモとしても分かりやすい。

---

## デモでの見せ方・トークの例
1. KPIで「**779ワード×47都道府県×266週（5年分）**を毎週自動追跡しています」と規模を掴ませる。
2. 全国Top10で「今週の日本の関心はサッカー・MLB・芸能。**47県中47県**でランクインした全国区の話題です」。
3. 県ごとの1位で「実は今週は**どの県も1位が同じ3語**。検索トレンドの上位は全国区なんです」と話す。
   → 県ごとの顔ぶれ・時系列を見たいときは P1 地域ビューへ（P3→P1の順で回すのも有効）。
