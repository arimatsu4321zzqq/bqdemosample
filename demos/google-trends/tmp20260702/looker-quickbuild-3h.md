# クイックビルド：3時間で4ページ作り切る手順

6つの手順書を行き来せず、**これ1枚で3時間走り切る**ための凝縮版。各チャートは「コア（必須）」と
「任意（時間が余ったら）」に分け、タイムボックスを超えたら任意を捨てて次ページへ進む。
詳細な操作やハマり対処は各ページ手順書と [`../../../docs/looker-studio-capabilities.md`](../../../docs/looker-studio-capabilities.md) を参照。

- データ: `ci-ss4-develop.demo_google_trends`（US）の `dash_jp_terms_weekly` / `dash_jp_region_latest` / `dash_jp_rising_recent`
- 原則: **タイマーを各区間でセット**。区間終了で未完でも次へ。仕上げ(最後の10分)で帳尻を合わせる。

---

## タイムテーブル（合計 3:00）

| 時間 | 区間 | ゴール |
|---|---|---|
| 0:00–0:30 | 共通セットアップ | データソース3本＋既定集計＋テーマ＋4ページ＋期間コントロール |
| 0:30–1:05 | P1 概況 | **地図をここで1回解決**（P2で再利用）＋KPI＋Top20＋時系列 |
| 1:05–1:40 | P2 地域比較 | 地図＋ランキング表＋クロスフィルタ |
| 1:40–2:10 | P3 ワード深掘り | ワード選択＋複数ワード折れ線＋比較表 |
| 2:10–2:50 | P4 急上昇 | Top15棒＋テーブル（＋余れば ヒートマップ） |

> 巻き返しポイント: 地図(P1)で15分以上詰まったら**即フォールバック**（下記）。ヒートマップ(P4)は任意。

## 0:00–0:30 共通セットアップ ★ここを丁寧に（後の全チャートが決まる）

1. 空レポート作成 → 名前「日本 検索トレンド ダッシュボード」。
2. BigQuery コネクタで**3テーブルを追加**（`ci-ss4-develop` → `demo_google_trends`）。名前を
   `週×ワード(全国)` / `都道府県×ワード(最新)` / `急上昇(直近52週)` に。
3. **フィールド型**（各データソースの編集画面で）:
   - `region_code` → **地域（国内地域・第1レベル）** ／ `week` → 日付 ／ `region_name` → テキスト
4. **既定の集計を修正（★最重要・飛ばさない）**:
   - `avg_score`→平均 / `max_score`→最大 / `best_rank`→**最小** / `region_count`→平均
   - `score`→平均 / `rank`→**最小** / `percent_gain`→**最大**
5. テーマ：アクセント`#2563EB`、地図の濃淡 淡`#DBEAFE`→濃`#1E3A8A`、キャンバス 1366×768。
6. ページを4枚（P1概況/P2地域比較/P3ワード深掘り/P4急上昇）＋ナビ＝左（またはタブ）。
7. **期間コントロール**を1つ置き「レポートレベルにする」。日付＝`week`、既定=過去12か月。

✅ チェック：どれかのデータソースで `avg_score` を表に出し、値が0〜100に収まる（SUMになっていない）。

---

## 0:30–1:05 P1 概況 — ★地図をここで確立

**コア**
- **日本地図**（地域別マップ / `都道府県×ワード(最新)`）: 地理ディメンション=`region_code`、色指標=`score`(平均)、
  **ズームエリア=日本**。⚠ 地域型になっていない/ズームが世界のままだと真っ白 → 直す。
  - ⚠ **15分で描画できなければフォールバック**：Googleマップ バブル＝各県の緯度経度で点表示（手順書 P1 の「フォールバック」節）。時間優先ならバブルでOK。
- **KPI スコアカード×3**（`週×ワード(全国)`）: `term`のCOUNT_DISTINCT / `week`のCOUNT_DISTINCT / `week`のMAX。
- **人気Top20 横棒**（`週×ワード(全国)`）: ディメンション=`term`、指標=`avg_score`、降順、行数20。
- **人気度 時系列**（`週×ワード(全国)`）: X=`week`、指標=`avg_score`。

**任意**：時系列に内訳ディメンション=`term`で複数ワード重ね／ワード検索ボックス。

期待値の目安：最新週=2026-06-28、Top付近はサッカー日本代表・ドジャース・芸能系がスコア100付近。

---

## 1:05–1:40 P2 地域比較 — ★地図はP1からコピペ

**コア**
- P1の地図を**コピー→このページに貼付**（設定済みなので数秒）。
- **都道府県×ワード ランキング表**（`都道府県×ワード(最新)`）: ディメンション=`region_name`,`term` / 指標=`rank`(最小),`score`(平均) / `rank`昇順。
- **都道府県ドロップダウン**（コントロール、`region_name`、複数選択）。
- **クロスフィルタリングON**（地図・表の設定 → 相互作用）。地図クリックで表が連動。

**任意**：県別 平均score 横棒（`region_name`→`score`平均 降順）／東京・大阪・北海道の2〜3県並置比較。

期待値：平均score 愛知70.3・神奈川68.8 が高く、長崎47.0 が低い。北海道=水曜どうでしょう等ご当地色。

## 1:40–2:10 P3 ワード深掘り

**コア**
- **ワード選択ドロップダウン**（コントロール、`term`、複数選択）＋検索ボックス。
- **複数ワード時系列 折れ線**（`週×ワード(全国)`）: X=`week`、指標=`avg_score`、**内訳ディメンション=`term`**。
- **ワード比較表**（`週×ワード(全国)`）: `term` × `avg_score`(平均),`max_score`(最大),`best_rank`(最小)。

**任意**：選択ワードKPI（`best_rank`最小＝最高順位 等）。
⚠ 浸透度(`region_count`)は常に47で平坦 → **作らない**（時間節約）。

デモ映えワード：`iphone 17`（秋ピーク）/`fifaワールドカップ2026`（初夏）/`サンリオキャラクター大賞`（夏）を重ねると山がズレて映える。

---

## 2:10–2:50 P4 急上昇

**コア**
- **急上昇Top15 横棒**（`急上昇(直近52週)`）: ディメンション=`term`、指標=`percent_gain`(最大)、降順、行数15。
- **直近で伸びた語 テーブル**: `week`,`region_name`,`term` × `percent_gain`(最大),`rank`(最小)、`week`降順。
- **percent_gain スライダー**（コントロール）で強いバズだけに絞れるように。

**任意**：**ヒートマップ**（ピボット表：行=`term`,列=`week`,指標=`percent_gain`最大 → 条件付き書式で色付け）。時間が余ったら。
⚠ 県別マップは全47県同値のため**作らない**（誤解を招く＋時間節約）。

期待値：上昇率トップは防災系（津波注意報 +51,800% 等）＋W杯・大谷翔平など時事語。

---

## 2:50–3:00 仕上げ
- 各ページ上部にタイトル帯（P1で作って全ページにコピペ）。
- 配色・フォント・チャートの位置揃え（グリッドスナップ）。
- 閲覧モードで4ページ切替＋期間コントロール＋クロスフィルタが効くか通し確認。

---

## 詰まったら即フォールバック（時間を溶かさない）
| 症状 | 対処 |
|---|---|
| 地図が真っ白 | `region_code`を地域型に／ズーム=日本。ダメなら緯度経度バブルへ |
| 数値が異常に大きい | 既定集計がSUMのまま → 平均/最大/最小へ修正 |
| ヒートマップに手間取る | 任意なので飛ばし、テーブル＋条件付き書式(棒表示)で代替 |
| 全体が押している | 各ページ「任意」を全部カット。コアだけで4ページ通す |
