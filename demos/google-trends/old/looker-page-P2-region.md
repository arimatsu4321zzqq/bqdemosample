# Looker Studio ページ手順書 — P2 地域比較（都道府県で見る検索トレンド）

「日本 検索トレンド ダッシュボード」の **2ページ目（P2 地域比較）** を手動で作る手順書。
共通の土台（レポート作成・データソース3本の追加・型/既定集計・テーマ・期間コントロール）は
**共通セットアップ手順書で完了済み**を前提とし、ここでは重複記載しない。

- 共通セットアップ: [`looker-setup-common.md`](./looker-setup-common.md)
- 操作の詳細リファレンス: [`looker-studio-capabilities.md`](../../../docs/looker-studio-capabilities.md)

> 用語: **ディメンション**=分類軸（都道府県・ワード等）／ **指標**=数値（score・rank）。

---

## このページで作るもの

テーマ＝**「都道府県で比べる」**。同じ週の全国スナップショットを使い、
「どの県が全体的に検索が活発か」「県ごとに何が刺さっているか（ご当地性）」を見せる。

主データソース: **`都道府県×ワード(最新)`（`dash_jp_region_latest`）**
補助データソース: **`週×ワード(全国)`（`dash_jp_terms_weekly`）**（全国基準との対比に使用）

### レイアウト（キャンバス 1366×768）

```
┌─────────────────────────────────────────────────────────────────────────┐
│  🗾 P2 地域比較     [都道府県▼(複数選択)]   [期間▼(レポート共通)]         │
├──────────────────────────────────┬──────────────────────────────────────┤
│ ② 都道府県別スコア地図           │ ③ 都道府県×ワード ランキング表       │
│    (地域別マップ / JP-13塗り分け) │    region_name | term | rank | score  │
│    色 = AVG(score)               │    (rank昇順)                         │
│    ▶ クリックでクロスフィルタ    │                                        │
│                                  │                                        │
├──────────────────────────────────┼──────────────────────────────────────┤
│ ④ 都道府県別 平均スコア（横棒）  │ ⑤ 2地域の並置比較                     │
│    region_name → AVG(score) 降順 │    選択県ごとの人気ワードTop           │
│    どの県が全体的に高いか         │    (ピボット表 region_name × term)    │
└──────────────────────────────────┴──────────────────────────────────────┘
```

> ⚠ **このデータの読み方（最重要・先に理解する）**: 最新週は全国共通の 73 ワードが
> **47 都道府県すべてに展開**されている（対象週 **2026-06-28**、47県×73ワード=3,431行）。
> そのため **上位 rank は全県ほぼ同じ顔ぶれ（同点1位が複数）** になる。
> **地域差は「同じワードのスコア（0〜100）の差」に表れる**。
> → 地図（②）とスコア差（⑤）で見るのが正解。rank だけを並べても県ごとの違いは出にくい。

## 事前確認（このページを作る前に）

- 共通セットアップ STEP 2 で、`dash_jp_region_latest` の
  **`region_code` = 地理(地域/国内地域第1レベル)** / **`score` = 平均(AVG)** / **`rank` = 最小値(MIN)** に
  設定済みであること。未設定ならスコアが SUM され地図・表が壊れる。
- 期間コントロールはレポートレベルで配置済み（P1で作成）。P2でも上部に表示される。
  ※ `dash_jp_region_latest` は最新週スナップショットのため期間の影響を実質受けない点に留意。

## ① コントロール（都道府県ドロップダウン ＋ 期間）

### 都道府県ドロップダウン
- **種類**: コントロール → ドロップダウンリスト（**複数選択**）
- **データソース**: `都道府県×ワード(最新)`
- **コントロールフィールド（ディメンション）**: `region_name`（英語表記。"Tokyo","Osaka Prefecture" 等）
- **指標**: なし（または `score`＝参考表示）
- **配置**: ヘッダー帯の右側、期間コントロールの左。

手順:
1. 「コントロールを追加 → ドロップダウンリスト」を配置。
2. データソース＝`都道府県×ワード(最新)`、コントロールフィールド＝`region_name`。
3. スタイルで「複数選択を許可」をオン、既定値は空（＝全県表示）。
4. ⚠ **適用スコープはページ単位**にする（このコントロールは P2 の全チャートに効かせ、他ページには波及させない）。
   コントロールを選択 →「データ」タブでスコープを確認。レポートレベルにはしない。

> ⚠ `region_code`（JP-13等）ではなく **`region_name` をコントロールに使う**。閲覧者に県名で選ばせるため。
> ジオコーディング（地図の塗り分け）に使うのは `region_code` の方（②参照）。役割を分ける。

### 期間コントロール
- 共通（レポートレベル）で配置済みのものをそのまま使う。P2 で追加作成は不要。

## ② 都道府県別スコア地図（地域別マップ）

- **チャート名**: `地図_都道府県別スコア`
- **種類**: 地域別マップ（Geo チャート）
- **データソース**: `都道府県×ワード(最新)`
- **地理ディメンション**: `region_code`（型＝地域/国内地域第1レベル。`JP-13` 形式）
- **色指標（既定集計）**: `score`（**平均 AVG**）
- **並べ替え**: なし（地図）
- **フィルタ**: なし（都道府県ドロップダウン①で絞り込み）
- **スタイル**:
  - ズームエリア（表示範囲）= **「日本」**（⚠ 必須。世界のままだと都道府県が見えない）
  - 色: 淡 `#DBEAFE` → 濃 `#1E3A8A`（共通テーマの地図濃淡）。「データなし」色は薄いグレー。
  - 最小/最大を自動、またはスケールを 45〜75 に手動固定すると県差が見やすい。
- **配置**: 左上（幅 ~640 × 高 ~330）。

手順:
1. 「グラフを追加 → 地域別マップ」を配置。
2. データソース＝`都道府県×ワード(最新)`。地理ディメンション＝`region_code`。
3. 指標＝`score`（既定集計が **AVG** になっているか必ず確認。SUM だと真っ濃になる）。
4. スタイルタブ → **ズームエリア＝日本**。色スケールを設定。
5. 「設定 → インタラクション → **クロスフィルタリング**」を **オン**（⑥で活用）。

> ⚠ **地図が描画されない/世界地図のまま**のとき: (a) ズームエリアが「日本」か、(b) `region_code` の型が
> 「地域(第1レベル)」か、を確認。それでも不安定なら `region_name`（英語名 "Tokyo" 等）に切替。
> 最終手段は緯度経度バブルマップ（詳細はリファレンス第3節）。

**期待結果（実データ 2026-06-28）**: 平均スコアの高い県が濃く出る。
最も濃い＝**愛知(70.3)・茨城(69.3)・神奈川(68.8)**、関東〜東海が濃いめ。
最も淡い＝**長崎(47.0)**、次いで和歌山(53.8)・長野(54.4)。全国で約 23 ポイントの濃淡差が出る。

## ③ 都道府県×ワード ランキング表

- **チャート名**: `表_県別ワードランキング`
- **種類**: 表（Table）
- **データソース**: `都道府県×ワード(最新)`
- **ディメンション**: `region_name`, `term`
- **指標（既定集計）**: `rank`（**最小値 MIN**）, `score`（**平均 AVG**）
- **並べ替え**: `rank` **昇順**（1位が上）
- **フィルタ**: なし（①のドロップダウン＋②のクロスフィルタで絞る）
- **スタイル**: 行数 = 100、`score` は **棒付き（データバー）** 表示にすると強弱が見える。ヘッダー固定。
- **配置**: 右上（幅 ~640 × 高 ~330）。

手順:
1. 「グラフを追加 → 表」を配置。データソース＝`都道府県×ワード(最新)`。
2. ディメンションに `region_name`, `term` を追加。
3. 指標に `rank`（MIN）, `score`（AVG）を追加。
4. 並べ替え＝`rank` 昇順。スタイルで `score` を棒付きに。

> ⚠ 何も絞らないと全県の同点1位が並び「同じワードだらけ」に見える。
> **②の地図で県をクリック**するとこの表がその県だけに絞られ、ご当地スコアが見える（⑥）。
> ①のドロップダウンで 2〜3 県に絞る運用でもよい。

**期待結果**: 未フィルタでは全県共通の話題（W杯・スポーツ・芸能）が上位に並ぶ。
実例（全県で rank1 同点）: **「ブラジル 対 日本」「橋本愛」「超ときめき宣伝部」「田中みな実」
「アスレチックス 対 ドジャース」「brazil vs japan」**。
東京に絞ると score 差で「**suica**（86）」「**路線価**（61）」が立ち上がる。

## ④ 都道府県別 平均スコア（横棒）

- **チャート名**: `横棒_県別平均スコア`
- **種類**: 横棒グラフ（Bar）
- **データソース**: `都道府県×ワード(最新)`
- **ディメンション**: `region_name`
- **指標（既定集計）**: `score`（**平均 AVG**）
- **並べ替え**: `score` **降順**（高い県が上）
- **フィルタ**: なし（①で絞り込み可）
- **スタイル**: 単色 `#2563EB`。データラベル表示。棒本数 = 15〜20（全 47 は多いので上位に制限、または縦スクロール）。

1. 「グラフを追加 → 横棒グラフ」を配置。データソース＝`都道府県×ワード(最新)`。
2. ディメンション＝`region_name`、指標＝`score`（AVG）。
3. 並べ替え＝`score` 降順。行制限を 20 程度に。

## ⑤ 2地域の並置比較（選択県ごとの人気ワードTop）

選んだ都道府県ごとに「その県で相対的に強いワード」を並べて見せる。ご当地性が最も伝わるパート。

- **チャート名**: `比較_県別ご当地ワード`
- **種類**: **ピボット表（Pivot Table）**（棒グラフでも可）
- **データソース**: `都道府県×ワード(最新)`
- **行ディメンション**: `term`
- **列ディメンション**: `region_name`
- **指標（既定集計）**: `score`（**平均 AVG**）
- **並べ替え**: 指標 `score` 降順
- **フィルタ**: ①の都道府県ドロップダウンで **比較したい 2〜3 県に絞る**（⚠ これが「2地域の並置」の要）
- **スタイル**: セルをヒートマップ（色スケール）に。淡→濃で県ごとの強弱が一目で分かる。
- **配置**: 右下（幅 ~640 × 高 ~330）。

手順:
1. 「グラフを追加 → ピボット表」を配置。データソース＝`都道府県×ワード(最新)`。
2. 行＝`term`、列＝`region_name`、指標＝`score`（AVG）。
3. スタイル → 指標を「ヒートマップ」表示に。
4. ①のドロップダウンで比較したい県（例: 東京・大阪・北海道）を選ぶ。

> ⚠ **棒グラフ版にする場合**: ディメンション＝`term`、内訳ディメンション＝`region_name`、
> 指標＝`score`（AVG）のグループ化縦棒にすると、同じワードの県間スコア差が棒の高さで直接比較できる。
> rank ではなく **score** を使うこと（rank は全県同点で差が出ない）。

**期待結果（実データ・ご当地スコアの実例）**
「その県のスコア − 全県平均スコア」で見た、**他県より突出して高い＝ご当地ワード**:

| 都道府県 | ご当地ワード | その県score | 全県平均 | 差 |
|---|---|---|---|---|
| 北海道 | **水曜 どうでしょう**（道内発の人気TV番組） | 72 | 32.8 | **+39** |
| 東京 | **suica**（交通系IC） | 86 | 48.9 | **+37** |
| 大阪 | **路線価** | 93 | 53.5 | **+40** |
| 大阪 | 阪神 対 中日（関西の野球） | 35→高め | — | — |
| 京都 | **路線価** / 阪神 対 中日 | 96 / 78 | 53.5 / 46.9 | +43 / +31 |
| 福岡 | **シャボン玉石鹸**（北九州の企業）/ ダブル台風情報 | 90 / 78 | 49.5 / 42.9 | +41 / +35 |
| 沖縄 | **シャボン玉石鹸** / 台風関連 | 100 | 49.5 | +51 |
| 愛知 | ソフトバンク 対 西武（野球） | 100 | 47.1 | +53 |

> 「水曜どうでしょう」は北海道発の伝説的ローカル番組、「suica」は首都圏の交通IC、
> 「路線価」「阪神 対 中日」は近畿（大阪・京都）、「シャボン玉石鹸」は九州（福岡・沖縄）。
> **同じ最新週でも、地域の生活・文化・地元企業・応援チームがスコア差にくっきり出る**のが見どころ。

## ⑥ クロスフィルタリング（地図クリック → 表が連動）

このページの体験の核。**②の地図で県をクリックすると、③④⑤がその県に絞られる**導線を作る。

手順:
1. ②地図、③表、④横棒、⑤ピボットの各チャートで
   「設定 → インタラクション → **クロスフィルタリング** をオン」。
2. ②地図で任意の県（例: 北海道）をクリック → 他チャートがその県に連動して絞り込まれることを確認。
3. もう一度同じ県をクリック、または余白クリックで選択解除。

> ⚠ **効かないとき**: 発信側（地図）と受信側（表など）の**両方**でクロスフィルタがオンか確認。
> ①のドロップダウン（ページ単位フィルタ）とクロスフィルタは併用でき、
> 「ドロップダウンで数県に絞る → 地図で1県クリックしてさらにドリル」という流れが自然。

## デモでの見せ方・トーク例（地域差の物語）

1. **「全国で今バズっているのは同じ」**: まず未フィルタの地図＋表を見せ、「W杯やスポーツ・芸能
   （ブラジル対日本、橋本愛…）は全国区で、どの県も1位が並ぶ」ことを示す。→ ここから「差はどこ?」に誘導。
2. **「差はスコアに出る」**: ④横棒で「愛知70.3 が最も検索が活発、長崎47.0 が最も控えめ。
   全国で20ポイント以上の温度差」と俯瞰。都市圏・東海が濃いことを地図②で確認。
3. **「ご当地ワードが刺さる」**: ⑤で北海道をクリック →「**水曜どうでしょう**が北海道だけ突出（+39）。
   これぞ道民のソウル番組」。東京なら「**suica**が首都圏でだけ跳ねる（+37）」。
4. **「関西と九州の色」**: 大阪・京都で「**路線価**と**阪神 対 中日**」、福岡・沖縄で「**シャボン玉石鹸**
   （北九州の地元企業）と台風情報」。「地元企業・応援チーム・天気が地域性そのもの」と語る。
5. **「クリックで深掘り」**: 地図クリック→表・ピボット連動をライブで見せ、
   「気になる県をクリックするだけで、その県の顔が分かる」インタラクティブ性を締めに。
