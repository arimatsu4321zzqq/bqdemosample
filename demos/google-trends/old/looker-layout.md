# Looker Studio 仮レイアウト案 — 検索トレンド分析（google_trends）

テーマ＝**地域×時系列のトレンド**。「今どこで何が伸びているか」を見せる。
各チャートは「Looker Studioのチャート種類 / ディメンション / 指標 / データソース」で定義。

> Looker Studio 全般の作り込み指針・チャート一覧・サンプル入手先は
> [`../../../docs/looker-common.md`](../../../docs/looker-common.md) を参照。

---

## 1ページ目レイアウト

```
┌──────────────────────────────────────────────────────────────────┐
│  🔍 検索トレンド分析        [国▼] [対象週▼] [ワード検索🔎]        │
├───────────────────┬───────────────────┬──────────────────────────┤
│ 対象国数          │ ユニークワード数  │ 最新更新週               │
│ 50                │ 8,200             │ 2026-06-15               │
├───────────────────┴───────────┬───────┴──────────────────────────┤
│ 国別 人気度（地域別マップ）    │ 急上昇ワードTop15（横棒）        │
│  [world choropleth, score]     │ ◯◯  +480%  ███████               │
│                                │ △△  +350%  █████                 │
│                                │ □□  +300%  ████                  │
├────────────────────────────────┼──────────────────────────────────┤
│ 人気ワード推移（時系列）       │ 国別 人気ワードTop（テーブル）   │
│  ワードを選ぶとscoreの週次推移 │ 国 | ワード | rank | score       │
└────────────────────────────────┴──────────────────────────────────┘
```

| # | チャート種類 | ディメンション | 指標 | 元データ |
|---|---|---|---|---|
| 1 | スコアカード×3 | — | CD(country_name) / CD(term) / MAX(refresh_date) | international_top_terms |
| 2 | 地域別マップ | country_name | AVG/MAX(score) | international_top_terms |
| 3 | 横棒グラフ | term（Top15） | MAX(percent_gain) | international_top_rising_terms |
| 4 | 期間（時系列）グラフ | week | score（特定termでフィルタ） | international_top_terms |
| 5 | テーブル | country_name, term | rank, score | international_top_terms |
| フィルタ | 国/対象週/ワード検索ボックス | | | |

> 日本に寄せるなら country_code='JP' でフィルタし「日本の急上昇ワード」ページを別途追加できる。
> 本デモの curated テーブル（`demo_google_trends.dash_*`）を使うとスキャン量が小さく高速。
> 集計テーブルの作り方は [`create_dashboard_tables.sql`](./create_dashboard_tables.sql) 参照。

## 複数ページ構成案 — 5ページ
| ページ | テーマ | 試す見せ方 |
|---|---|---|
| P1 グローバル概況 | 世界俯瞰 | 世界地図(塗り分け)＋KPI |
| P2 国別ランキング | 国比較 | 横棒ランキング、国別テーブル、国フィルタ |
| P3 ワード深掘り | 単語トレンド | 複数ワード時系列比較（折れ線） |
| P4 急上昇ウォッチ | 伸び率 | percent_gainランキング、増減インジケータ |
| P5 日本フォーカス | JP特化 | country_code=JP固定の人気/急上昇 |
