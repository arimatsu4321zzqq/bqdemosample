# P1 概況 ページ作成手順

前提: [`looker-setup-common.md`](./looker-setup-common.md)（データソース3本追加・型/既定集計・テーマ・ナビ・レポートレベル期間コントロールは設定済み）。機能詳細は [`looker-studio-capabilities.md`](../../docs/looker-studio-capabilities.md) を参照。本ページはデータソース `週×ワード(全国)`（= `dash_jp_terms_weekly`）と `都道府県×ワード(最新)`（= `dash_jp_region_latest`）を使う。

## このページで作るもの
全国の検索トレンドを一望する「サマリ画面」。KPI3枚＋日本地図＋人気ワードTop20＋時系列トレンド＋コントロール2種。開くだけで「いつ・何が・どこで人気か」が分かる。

### レイアウト図（キャンバス 1366×768）
```
┌──────────────────────────────────────────────────────────────┐
│  [共通ヘッダー帯：日本 検索トレンド ダッシュボード / P1 概況]        │
├───────────────┬───────────────┬──────────────────────────────┤
│ KPI①対象ワード │ KPI②対象週数   │ KPI③最新更新週                  │
│ 779            │ 266            │ 2026-06-28                    │

│   地図_都道府県別スコア   ├──────────────────────────────────────┤

│  時系列_人気度トレンド (X=week / AVG(avg_score) / 内訳=term)        │
└──────────────────────────────────────────────────────────────┘
```

## 0. 事前準備
1. 左ナビで **P1 概況** ページを開く。
2. 共通ヘッダー帯（長方形＋タイトル）が無ければ他ページからコピペ。サブタイトルに「P1 概況」を入れる。
3. グリッドスナップ ON（10px）を確認。

---

## 1. KPI スコアカード ×3

| 項目 | 内容 |
|---|---|
| チャート種類 | スコアカード (Scorecard) |
| データソース | 週×ワード(全国) `dash_jp_terms_weekly` |
| フィルタ | なし（レポートレベル期間コントロールの影響は受ける） |
| 配置 | ヘッダー直下に横3分割（各 幅約440×高さ90） |

**手順**
1. 「グラフを追加 → スコアカード」を3つ配置。
2. それぞれ指標を設定（ディメンションは無し）:
   - **KPI_対象ワード数**: 指標 = `term`、集計を **COUNT_DISTINCT（個別カウント）** に変更。
   - **KPI_対象週数**: 指標 = `week`、集計を **COUNT_DISTINCT** に変更。
   - **KPI_最新更新週**: 指標 = `week`、集計を **最大値(MAX)** に変更。
3. スタイル → 各カードにタイトルラベル（「対象ワード数」「対象週数」「最新更新週」）を表示。数値は大きめフォント、色 `#0F172A`。

> ⚠ スコアカードの既定集計は SUM。`term`/`week` は必ず **COUNT_DISTINCT**、最新週は **MAX** に変える。放置すると桁の壊れた合計値が出る。

**期待される表示結果（全期間）**
- 対象ワード数 = **779**
- 対象週数 = **266**
- 最新更新週 = **2026-06-28**
（期間コントロールを「過去12か月」等に絞ると、対象週数・ワード数はその期間の値に減る。最新更新週は変わらず 2026-06-28。データ全体の期間は 2021-05-30〜2026-06-28。）

## 2. 日本地図（地域別マップ）

| 項目 | 内容 |
|---|---|
| チャート名 | 地図_都道府県別スコア |
| チャート種類 | 地域別マップ (Geo チャート) |
| データソース | 都道府県×ワード(最新) `dash_jp_region_latest` |
| 地理ディメンション | `region_code`（**地域＝国内地域第1レベル**。`JP-13` 形式） |
| 色指標 | `score`、集計 = **平均(AVG)** |
| ズームエリア | **日本** |
| フィルタ | なし（このテーブルは最新週スナップショット。47都道府県分） |
| 配置 | 左下ブロック（幅約540×高さ430） |

**手順**
1. 「グラフを追加 → 地域別マップ」を配置。
2. 地理ディメンション = `region_code`。共通手順書で型を「地域(国内地域第1レベル)」に設定済みであることを確認（未設定ならデータソースでその型に変更）。
3. 色指標 = `score`（既定集計は AVG のはず。念のため確認）。
4. スタイル → **ズームエリア = 日本**。
5. スタイル → 色の濃淡: 最小 `#DBEAFE`（淡）→ 最大 `#1E3A8A`（濃）。データなし色はグレー。

> ⚠ **3大ハマりどころ**:
> 1. ズームを「日本」にしないと世界地図のまま＝都道府県が見えない。
> 2. `region_code` の型が「テキスト」のままだとジオコーディングされない。必ず「地域(第1レベル)」型に。
> 3. 塗り分けが出ない場合は、地理ディメンションを `region_name`（英語名 "Tokyo","Aichi Prefecture"）に切替えて再試行。それでも不安定なら Google マップのバブルマップ（緯度経度）にフォールバック（capabilities 3節）。

**期待される表示結果（最新週 2026-06-28・平均スコア上位）**
| 順 | region_code | 都道府県 | AVG(score) |
|---|---|---|---|
| 1 | JP-23 | 愛知 (Aichi) | 70.3 |
| 2 | JP-08 | 茨城 (Ibaraki) | 69.3 |
| 3 | JP-14 | 神奈川 (Kanagawa) | 68.8 |
| 4 | JP-01 | 北海道 (Hokkaido) | 68.2 |
| 5 | JP-11 | 埼玉 (Saitama) | 68.2 |
| 6 | JP-27 | 大阪 (Osaka) | 67.8 |
| 7 | JP-13 | 東京 (Tokyo) | 67.7 |

47都道府県すべてが塗られ、値は概ね 60〜70 台に収まる（極端な濃淡差は小さい＝全国的に関心が均一）。愛知・茨城・神奈川あたりがやや濃く出れば成功。

## 3. 人気ワード Top20（横棒）

| 項目 | 内容 |
|---|---|
| チャート名 | 棒_人気ワードTop20 |
| チャート種類 | 横棒グラフ (Bar) |
| データソース | 週×ワード(全国) `dash_jp_terms_weekly` |
| ディメンション | `term` |
| 指標 | `avg_score`、集計 = **平均(AVG)** |
| 並べ替え | `avg_score`（AVG）**降順** |
| 行数 | **20** |
| フィルタ | 期間コントロールで最新週付近に絞ると「今の人気」になる |
| 配置 | 右中ブロック（幅約780×高さ300） |

**手順**
1. 「グラフを追加 → 棒グラフ（横棒）」を配置。
2. ディメンション = `term`、指標 = `avg_score`（AVG）。
3. 並べ替え = `avg_score` 降順。
4. スタイル → **表示するバーの数 = 20**（または設定 →「行数」= 20）。
5. スタイル → バー色は単色アクセント `#2563EB`。データラベル ON（値を表示）。

> ⚠ 「行数(表示バー数)」を絞らないと全779ワードが縦に潰れて読めない。必ず **20行＋降順** をセットで。期間を全期間にすると往年の話題も混ざるので、デモでは期間を直近に寄せると「今」らしくなる。

**期待される表示結果（最新週 2026-06-28・AVG(avg_score)降順 Top10）**
1. 橋本愛 — 100.0
2. 田中みな実 — 100.0
3. オランダ 対 モロッコ — 100.0
4. クーニャ — 100.0
5. ブラジル 対 日本 — 100.0
6. 塩貝 — 100.0
7. アスレチックス 対 ドジャース — 99.3
8. パラグアイ — 99.0
9. ブラジル スタメン — 97.7
10. ブルージェイズ 対 メッツ — 97.1

（続き: 田中碧 96.9 / 堂安 95.0 / 佐野海舟 逮捕 90.7 / 中国輸出規制リスト 87.8 / 中曽根 愛子 さま 87.5 / brazil vs japan 86.1 / アンチェロッティ 84.2 / マツダ ロードスターrf 83.8 / ビニシウス 82.3 / 超ときめき宣伝部 81.7）
→ サッカー日本代表戦・MLB・芸能人が上位。スコア100付近が横並びで並ぶ棒が出れば成功。

## 4. 人気度の時系列トレンド（期間グラフ）

| 項目 | 内容 |
|---|---|
| チャート名 | 時系列_人気度トレンド |
| チャート種類 | 期間 / 時系列 (Time Series) |
| データソース | 週×ワード(全国) `dash_jp_terms_weekly` |
| X軸(ディメンション) | `week` |
| 指標 | `avg_score`、集計 = **平均(AVG)** |
| 内訳ディメンション | `term`（任意。系列を分割） |
| 並べ替え | `week` 昇順 |
| フィルタ | レポートレベル期間コントロールに追従 |
| 配置 | 最下段フル幅（幅約1300×高さ180） |

**手順**
1. 「グラフを追加 → 期間(時系列)」を配置。
2. X軸 = `week`、指標 = `avg_score`（AVG）。
3. （任意）内訳ディメンション = `term`。ただし779ワード全部だと線が過密になるため、**ワード検索コントロール（下の5）で数語に絞る前提**で使う。内訳なしなら「全国平均スコアの推移」1本線になる。
4. スタイル → 線色はテーマパレット。内訳を使う場合は凡例をグラフ下に。

> ⚠ 内訳 `term` を付けたまま絞り込みが無いと線が数百本になり判読不能。既定は「内訳なし（全国平均1本）」にし、ワード検索で選ばせるのが安全。

**期待される表示結果**
週次の平均スコアが 2021-05-30〜2026-06-28 の範囲で推移。内訳なしなら緩やかな1本線、ワードを選ぶとそのワードのスパイク（話題化した週の山）が見える。例: 「ブラジル 対 日本」を選ぶと試合週に急峻なピーク。

---

## 5. コントロール（このページ用）

| コントロール | 種類 | 対象フィールド | 配置 |
|---|---|---|---|
| 期間 | 期間コントロール (date range) | `week` | ※共通手順書でレポートレベルに設置済みなら再配置不要。無ければこのページ上部右に追加 |
| ワード検索 | 入力ボックス(検索ボックス) | `term` | KPIとTop20の間、右上 |

**手順**
1. 期間コントロール: レポートレベルの共通コントロールが効いていることを確認（共通手順書 STEP5）。ページ内に無ければ「コントロールを追加 → 期間」を配置し、日付ディメンション = `week`。
2. ワード検索: 「コントロールを追加 → 入力ボックス」を配置。コントロールフィールド = `term`。データソース = 週×ワード(全国)。
3. ワード検索の適用範囲がページ内チャート（Top20・時系列）に効くことを確認。

> ⚠ 入力ボックスは `term` を対象に。閲覧者が「ブラジル」等と打つと Top20と時系列が絞られる。地図は別データソース（最新週スナップショット）なので `term` 検索は効かない点に留意（地図は全ワード平均のまま）。

---

## デモでの見せ方・トークの例
1. 「開いた瞬間に、対象 **779ワード×266週**、最新は **2026-06-28** と分かります。データは5年分（2021年〜）」とKPIで掴む。
2. 地図を指して「今週は **愛知・茨城・神奈川** の関心がやや高い。ただ全国どこも60〜70台で、話題は全国区だと読めます」。
3. Top20で「**サッカー日本代表戦（ブラジル戦・オランダ対モロッコ）、MLB（ドジャース）、芸能（橋本愛・田中みな実）** が今の三本柱」と紹介。
4. ワード検索に「ブラジル 対 日本」と入力 → Top20と時系列が連動し、試合週のスパイクを見せて「イベント連動で検索が跳ねる様子がリアルタイムに追える」。
5. 期間コントロールを直近3か月に絞り「フィルタ1つで“今の旬”に切り替わる」ことを実演し、P2地域比較・P4急上昇へ誘導。
