# P1 地域ビュー ページ作成手順

前提: [`looker-setup-common.md`](./looker-setup-common.md)（データソース2本・型/既定集計・県名/month 計算フィールド・テーマ・3ページ設定済み）。
実物イメージ: [`mock/P1.png`](./mock/P1.png)。

## このページで作るもの
「県を選ぶ → 今週の顔ぶれ・時系列・地元ワードが切り替わる」主役ページ。
コントロール＋表（Top10）＋KPI＋時系列＋地元ワード＋Top25明細。

### レイアウト図（キャンバス 1366×768）
```
┌────────────────────────────────────────────────────────────┐
│ [ヘッダー帯] 検索トレンド 地域ビュー   (最新週: MAX(week))        │
│ [都道府県▼] [ワード検索🔎]                                       │
├─────────────────────────┬──────────────────┤
│ 表_今週の顔ぶれTop10（順位 | ワード）   │ KPI_今週のランクイン数    │
│                                      │ KPI_追跡週数             │
├─────────────────────────┴──────────────────┤
│ 時系列_スコア推移（ワード検索で選んだ語を重ねる）＋読み方注記        │
├─────────────────────────┬──────────────────┤
│ 表_この県の地元ワード（棒付き表）       │ 表_今週のTop25（明細）    │
└─────────────────────────┴──────────────────┘
```

## 1. コントロール ×2（先に置く）

| コントロール | 種類 | フィールド | データソース | 備考 |
|---|---|---|---|---|
| 都道府県▼ | プルダウン リスト | `県名`（計算フィールド） | 週次明細 | スタイル→**単一選択**。フィールドID統一済みなら**週数集計のチャート（地元ワード）にも効く** |
| ワード検索 | 入力ボックス | `term` | 週次明細 | **検索タイプを「含む」に変更**（既定は完全一致のため必須）。時系列とTop25に効く |

> ⚠ 前提: 共通手順書の補足1（`県名` のフィールドID統一）を**チャート構築前に**済ませていること。
> 地元ワード表（週数集計）に都道府県▼が効かない場合はID不一致が原因（同補足のフォールバック参照）。
> **ブレンドは使わない方針**。

## 2. 表_今週の顔ぶれTop10

| 項目 | 内容 |
|---|---|
| チャート種類 | 表 |
| データソース | 週次明細 |
| ディメンション | `term` |
| 指標 | `latest_rank`（**MIN**）。列名を「順位」に変更 |
| 並べ替え | `latest_rank` **昇順** |
| 行数 | 10（ページングOFF） |
| チャート単位フィルタ | **`is_latest_week` = true** |
| 配置 | 左上（幅約700×高さ300） |

> ⚠ `is_latest_week` フィルタを忘れると、過去週の行（latest_rank=NULL）が混ざって順位が出ない。
> ⚠ スコア列は置かない（ワード間比較に見えてしまうため。方針は [`data-flow.md`](./data-flow.md) §3）。

**期待される表示結果（都道府県▼=大阪府・2026-06-28週）**:
1位 オランダ 対 モロッコ / 2位付近に ブラジル 対 日本・田中みな実・橋本愛 など（同点タイあり）。

## 3. KPI スコアカード ×2

| チャート名 | データソース | 指標 | 設定 |
|---|---|---|---|
| KPI_今週のランクイン数 | 週次明細 | `term` → **COUNT_DISTINCT** | フィルタ: is_latest_week=true |
| KPI_追跡週数 | 週次明細 | `week` → **COUNT_DISTINCT** | フィルタなし |

**期待される表示結果**: ランクイン数 ≈ 25前後（県・タイで変動）／追跡週数 **266**（再実行時期で増える）。

## 4. 時系列_スコア推移

| 項目 | 内容 |
|---|---|
| チャート種類 | 期間（時系列） |
| データソース | 週次明細 |
| X軸 | `week` ／ **内訳ディメンション = `term`** |
| 指標 | `score`（**AVG**） |
| 配置 | 中段フル幅（幅約1300×高さ220） |

**手順の要点**
1. 既定では線が全ワード分になり判読不能 → **ワード検索で1〜3語に絞って見せる**運用。
2. チャート直下にテキスト部品で読み方注記:
   「高さ＝そのワード自身のピーク比。**量の比較ではなく、山の位置＝盛り上がった時期**を読む」。

**期待される表示結果**: 「ブラジル 対 日本」で検索 → 直近週に急峻なスパイク。
「栗きんとん」→ 毎年12月と9〜10月に山が繰り返す。

## 5. 表_この県の地元ワード（棒付き表）

| 項目 | 内容 |
|---|---|
| チャート種類 | 表（棒付き） |
| データソース | **週数集計** |
| ディメンション | `term` |
| 指標 | `share`（**MAX**・棒表示）／`ranked_weeks`（SUM） |
| 並べ替え | `share` 降順 |
| チャート単位フィルタ | **`is_local_term` = true** |
| 配置 | 左下（幅約640×高さ200） |

> ⚠ 都道府県▼が効くのはフィールドID統一（共通手順書 補足1）が済んでいる場合。
> 効かないときはID不一致 →「フィールド名とIDの管理」で `県名` のIDを両ソースで揃える。

**期待される表示結果（大阪府・実測）**: 大阪府警察 68% / 高野 線 62% / 大阪 警報 41% / 南海電鉄 30%。
地元ワードが無い県では0行になる（全国で27語のみ。それ自体をデモの話題にできる）。

## 6. 表_今週のTop25（明細）

表（週次明細 / term / MIN(latest_rank) 昇順 / 25行＋ページング / フィルタ is_latest_week=true）。
ワード検索が効くので「表の中から気になる語を検索→時系列で見る」動線になる。配置は右下。

## デモでの見せ方・トークの例
1. 都道府県▼で **大阪府** →「今週の大阪の検索1位は『オランダ 対 モロッコ』。W杯・MLB・芸能が上位です」。
2. ワード検索に「ブラジル 対 日本」→ 時系列のスパイクを指して「**試合の週だけ**跳ねる。話題の寿命が見えます」。
3. 地元ワードを指して「全国どこでも顔ぶれは似ますが、**大阪だけは『大阪府警察』『高野線』『南海電鉄』が
   出続けます**。これがこの県ならではの検索です」（→ 県を切り替えて地元ワードだけ変わるのを見せる）。
4. 最後に Conversational Analytics へ「**大阪の地元ワードを教えて**」と聞き、同じ答えが返るのを見せる。
