# Looker Studio レイアウト案 — 検索トレンド 地域ビュー（google-trends）

テーマ＝**県で絞る×時系列**。「この県でいま何が検索されているか」「いつ盛り上がったか」「この県ならではの語」を見せる。
レイアウトの実物イメージは [`mock/`](./mock/)（HTML＋P1〜P3キャプチャ）を参照。

> Looker Studio 全般の指針は [`../../docs/looker-common.md`](../../docs/looker-common.md)、
> 機能の可否は [`../../docs/looker-studio-capabilities.md`](../../docs/looker-studio-capabilities.md) を参照。

## 設計の大原則（データ由来。全ページ共通）

1. **score の大小はワード間・県間とも比較しない**（全35,489系列が自己ピーク=100。[`data-flow.md`](./data-flow.md) §3）。
   score は時系列チャート（いつ盛り上がったか）専用。
2. ワード間・県間の比較は **順位（latest_rank・最新週のみ）** と **ランクイン週数・県数**（`jp_term_region_weeks`）で行う。
3. **地図は使わない**（人気語の77%が全県共通で塗り分けが嘘っぽくなるため。県選択はドロップダウンで足りる）。
4. 「急上昇」の専用データは無い。ダッシュボードでは扱わず、聞かれたらエージェント側が4週前比で近似する。

|---|---|---|
| P1 地域ビュー | 県で絞る「今週の顔ぶれ」＋時系列＋地元ワード | 週次明細（+週数集計） |

## P1 地域ビュー（主役ページ）

```
┌────────────────────────────────────────────────────────────┐
│ 🗾 検索トレンド 地域ビュー  [都道府県▼] [ワード検索🔎] (最新週チップ) │
├──────────────────────────┬─────────────────┤
│ 表_今週の顔ぶれTop10（順位=latest_rank）  │ KPI（ランクイン数等）    │
├──────────────────────────┴─────────────────┤
│ 時系列_スコア推移（ワード検索で選んだ語を重ねる。読み方注記つき）      │
├──────────────────────────┬─────────────────┤
│ 表_この県の地元ワード（is_local_term）    │ 表_今週のTop25（明細）   │
└──────────────────────────┴─────────────────┘
```

| # | チャート種類 | ディメンション | 指標 / 並べ替え | データソース |
|---|---|---|---|---|
| 1 | 表 | term | MIN(latest_rank) 昇順・10行（フィルタ: is_latest_week=true） | 週次明細 |
| 2 | 期間（時系列） | week（内訳=term） | AVG(score)（ワード検索で絞る前提） | 週次明細 |
| 3 | 表（棒付き） | term | MAX(share) 降順（フィルタ: is_local_term=true） | 週数集計 |
| 4 | 表 | term | MIN(latest_rank) 昇順・25行＋ページング | 週次明細 |
| コントロール | 都道府県▼（`県名`・単一選択。**フィールドID統一で両データソースに効かせる**） / ワード検索（入力ボックス・**検索タイプ=含む**） | | | 週次明細（ID統一で集計にも波及） |

## P2 ワード深掘り

| # | チャート種類 | ディメンション | 指標 | データソース |
|---|---|---|---|---|
| 1 | KPI スコアカード | — | COUNT_DISTINCT(week)（=ランクインした週数）/ MAX(week) | 週次明細 |
| 2 | 期間（時系列・全期間） | week | AVG(score) | 週次明細 |
