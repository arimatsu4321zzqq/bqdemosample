# Looker Studio ページ手順書 — P4 急上昇ウォッチ（バズ検知）

「日本 検索トレンド ダッシュボード」の4ページ目 **P4 急上昇ウォッチ** を手動で作る手順書。
テーマは **バズ検知** ＝「直近で何が・どの週に・どこで急上昇したか」を追う。

> 本ページは共通セットアップが完了している前提。データソース追加・フィールド型/既定集計・テーマ・
> 期間コントロール等の土台は繰り返さない。必ず先に下記2つを読むこと。
> - 共通セットアップ: [`looker-setup-common.md`](./looker-setup-common.md)
> - 機能リファレンス: [`looker-studio-capabilities.md`](../../docs/looker-studio-capabilities.md)

---

## 使うデータ

- データソース: **`急上昇(直近52週)`**（BQ テーブル `ci-ss4-develop.demo_google_trends.dash_jp_rising_recent` / ロケーション US）
- 粒度: **都道府県 × 週 × ワード**（急上昇・直近52週・各週 rank<=10）
- フィールド:

| フィールド | 型 | 意味 | このページでの既定集計 |
|---|---|---|---|
| `region_code` | 地理（地域/国内地域第1レベル, `JP-13`形式） | 都道府県コード。**地図はこれを使う** | — |
| `region_name` | テキスト | 都道府県名（`Tokyo`,`Osaka Prefecture`等）。ラベル・ドロップダウン用 | — |
| `week` | 日付（週） | 対象週。時系列・ピボット列軸 | — |
| `term` | テキスト | 検索ワード | — |
| `percent_gain` | 数値 | **上昇率(%)**。話題性・バズの主指標 | **最大値 (MAX)** |
| `score` | 数値 | 相対検索量(0-100) | 平均 (AVG) |
| `rank` | 数値 | 急上昇順位（1が最上位） | **最小値 (MIN)** |

> ⚠ **なぜ `percent_gain` を MAX にするか**: このテーブルは (都道府県×週×ワード) で既に集計済み。
> Looker は「既定の集計」で再集計するため、放置すると `percent_gain` を SUM して上昇率が壊れる。
> バズは「**最も伸びた瞬間の値**」を見たいので **MAX** が正しい。`rank` は「1が最上位」なので **MIN**。

## このページで作るもの

1. **コントロール**: 都道府県ドロップダウン(`region_name`)／期間／`percent_gain` スライダー（下限を上げて強いバズだけに絞る）
2. **急上昇ワード Top15**（横棒）: `term` × MAX(`percent_gain`)、降順、15行
3. **直近で伸びた語 テーブル**: `week` / `region_name` / `term` / MAX(`percent_gain`) / MIN(`rank`)、week 降順
4. **急上昇ヒートマップ**（ピボット表＋条件付き書式）: 行=`term`、列=`week`、指標=MAX(`percent_gain`)
5. **都道府県別 急上昇**（地域別マップ or 横棒）: `region_code` → MAX(`percent_gain`)

> ⚠ **このデモデータの性質（必読）**: `dash_jp_rising_recent` は **全国の急上昇データを47都道府県すべてに
> 同じ値で複製**した構造（実測: 同一 term×week の `percent_gain`/`rank`/`score` が全県一致、各県とも
> distinct term 数=184）。したがって **⑤の地図は「特定県だけ濃い」にはならず、全国イベント（災害・スポーツ）で
> 全県が一斉に濃くなる**。これはバグではなくデータ仕様。デモでは「災害・W杯は全国同時にバズる」という
> **正しい物語**として説明する（下部トーク例参照）。県ごとの濃淡差を見せたい場合は P2 地域比較ページを使う。

## ② 急上昇ワード Top15（横棒グラフ）

- **チャート名**: `横棒_急上昇ワードTop15`
- **種類**: 横棒グラフ（Bar / 横向き）
- **データソース**: `急上昇(直近52週)`
- **ディメンション**: `term`
- **指標**: `percent_gain`（**集計=MAX**）
- **並べ替え**: `percent_gain` **降順**
- **フィルタ**: なし（コントロールのスコープに従う）
- **配置**: 左上ブロック

手順:
1. 「グラフを追加 → 棒グラフ → 横棒」を配置。
2. データソースを `急上昇(直近52週)` に。
3. ディメンションに `term`。
4. 指標に `percent_gain` → 指標名クリックで**集計を MAX** に変更。
5. 「スタイル → 棒の数（表示する行数）」を **15** に。
6. 「並べ替え」= `percent_gain` / **降順**。
7. スタイル: 単色バー `#F59E0B`（橙＝急上昇）。データラベル ON、値は `%` 表示。

## ③ 直近で伸びた語（テーブル）

- **チャート名**: `表_直近で伸びた語`
- **種類**: 表（Table）
- **データソース**: `急上昇(直近52週)`
- **ディメンション**: `week` / `region_name` / `term`
- **指標**: `percent_gain`（**MAX**） / `rank`（**MIN**）
- **並べ替え**: `week` **降順**（第2ソート: `percent_gain` 降順）
- **フィルタ**: なし（コントロール従属）
- **配置**: 右上ブロック

手順:
1. 「グラフを追加 → 表」を配置、データソース `急上昇(直近52週)`。
2. ディメンションを `week`, `region_name`, `term` の順に追加。
3. 指標に `percent_gain`(MAX) と `rank`(MIN)。
4. 並べ替え = `week` 降順。「行数」= 25〜50。
5. スタイル: `percent_gain` 列を **棒付きセル（バー表示）** にすると伸びが直感的（表のスタイル→指標→バー）。
6. 見出しを日本語化: `week`→「週」、`region_name`→「都道府県」、`term`→「ワード」、`percent_gain`→「上昇率(%)」、`rank`→「順位」。

**期待結果（実データ・最新週 2026-06-28 付近）**: `美輪 明宏`(+14,200%)、`後藤 輝樹`(+8,600%)、
`オランダ 対 モロッコ`(+7,700%) などが最上部に来る。週を下るほど過去のバズ語（津波・地震・FIFA）が並ぶ。
`rank` は上位バズ語で **1** が並ぶ。

> ⚠ データが全県一致のため、`region_name` を入れると同じ (week, term) が47行に増える。デモでは
> **都道府県ドロップダウンで1県に絞る**か、`region_name` を外して (week, term) の全国ビューにすると見やすい。

## ④ 急上昇ヒートマップ（ピボット表＋条件付き書式）

- **チャート名**: `ピボット_急上昇ヒートマップ`
- **種類**: **ピボット表**（Pivot Table）
- **データソース**: `急上昇(直近52週)`
- **行ディメンション**: `term`
- **列ディメンション**: `week`
- **指標**: `percent_gain`（**MAX**）
- **並べ替え**: 行=`percent_gain`(MAX) 降順 / 列=`week` 昇順（左→右で時間が進む）
- **フィルタ**: 行が多すぎるため `percent_gain` スライダー（コントロール）で強いバズだけに絞るのが前提
- **配置**: 中段フル幅

手順:
1. 「グラフを追加 → ピボット表」を配置。データソース `急上昇(直近52週)`。
2. **行ディメンション** に `term`。
3. **列ディメンション** に `week`。
4. **指標** に `percent_gain` → **集計 MAX**。
5. 行の並べ替え = `percent_gain` 降順、行数 = 15。列（week）は昇順。
6. **★ヒートマップ化（迷いやすい）**: 「スタイル」タブ → 指標 `percent_gain` の**「セルの表示形式」を「ヒートマップ」**に変更（＝**条件付き書式**）。
   - 単一グラデーション。最小色 `#DBEAFE`（淡青）→ 最大色 `#1E3A8A`（濃紺）または橙系 `#7C2D12`。
   - 「数値」表示より色ブロックの方がバズが読みやすい（値は残してもよい）。

> ⚠ **ここが一番の勘所**: 「ヒートマップ」は**普通の表/ピボット表の *条件付き書式（セルの表示形式=ヒートマップ）*
> で作る**。専用の「ヒートマップ」チャート種類を探さないこと。**色が濃いセル＝その週にその語が強く伸びた**。
> ⚠ **列(week)が52本あると横に潰れる**ので、**期間コントロールで直近8〜12週に絞る**か、隔週表示にする。

**期待結果（実データ）**: 上位語（津波注意報・地震・FIFA順位表・土砂災害警報）の行が全体的に濃い帯になる。
このデモデータは各語の `percent_gain` が在籍週を通じてほぼ一定のため、**単発の1セルだけ濃い**より
**行ごと横帯で濃い**見え方になる（＝その語が長期間トレンド入りしていた）。実運用の生データでは
イベント週だけ濃くなる「点」パターンになる。

## ⑤ 都道府県別 急上昇（地域別マップ／横棒）

- **チャート名**: `地図_都道府県別急上昇`
- **種類**: 地域別マップ（Geo チャート）。塗り分けが不安定なら横棒にフォールバック。
- **データソース**: `急上昇(直近52週)`
- **地理ディメンション**: `region_code`（型=**地域/国内地域第1レベル**、`JP-13`形式）
- **色指標**: `percent_gain`（**MAX**）
- **フィルタ**: コントロール従属
- **配置**: 下段フル幅

手順（地域別マップ）:
1. 「グラフを追加 → 地域別マップ（Geo チャート）」を配置。データソース `急上昇(直近52週)`。
2. 地理ディメンションに `region_code`（共通手順で型を「地域(国内地域第1レベル)」に設定済み）。
3. 色指標に `percent_gain` → **集計 MAX**。
4. **★ズームエリア（表示範囲）を「日本」または「地域(Region)」に設定**（世界のままだと都道府県が見えない）。
5. スタイル: 色の最小 `#DBEAFE` → 最大 `#1E3A8A`。データなし色は薄グレー。

代替（横棒）: ディメンション=`region_name`、指標=MAX(`percent_gain`)、降順。塗り分けの検証が面倒な
デモ現場ではこちらが確実。

> ⚠ **このデモデータでは全47都道府県が同一値**（実測 max=+51,800% が全県一致、いずれも最大の語は
> `津波 注意 報`）。よって**地図は「特定県だけ濃い」にはならず全県が同じ濃さ**になる。これはデータ仕様
> （全国データを各県に複製）。デモでは「災害・W杯は**全国同時多発的にバズる**」という説明に使う。
> 県ごとの差を見せたいときは P2 地域比較（`dash_jp_region_latest`）へ誘導する。

**期待結果（実データ・都道府県別 MAX 上昇率）**:

| 都道府県 | region_code | MAX(上昇率) | 最大の語 |
|---|---|---|---|
| Hokkaido / Aomori / Iwate / Miyagi / … | JP-01,02,03,04 … | +51,800%（全県一律） | 津波 注意 報 |
| （47都道府県すべて同値） | JP-01〜JP-47 | +51,800% | 津波 注意 報 |

## コントロール（このページ上部）

> ⚠ 期間コントロールは共通手順で**レポートレベル**に配置済み。ここでは**ページ固有**の2つを追加する。

### C1. 都道府県ドロップダウン
- 種類: ドロップダウンリスト（単一/複数選択）
- コントロールフィールド: `region_name`
- 手順: 「コントロールを追加 → プルダウンリスト」→ フィールド `region_name`。既定値=全件。
- 配置: 上部帯・左寄り。

### C2. 上昇率(%)スライダー（強いバズだけに絞る）
- 種類: スライダー（数値レンジ）
- コントロールフィールド: `percent_gain`
- 手順: 「コントロールを追加 → スライダー」→ フィールド `percent_gain`。
- 使い方: **下限を 1,000 や 5,000 に上げる**と、弱い上昇を切り捨て**強いバズだけ**が全チャートに残る。
- 配置: 上部帯・右寄り。

> ⚠ **スライダーのスコープ（適用範囲）に注意**: このスライダーは**ページ内の全チャートに効かせたい**ので、
> 上部帯のコントロール群と同じページ上に置き、特定チャートだけに紐づけない（チャートを選択した状態で
> コントロールを作ると**そのチャート専用フィルタ**になってしまう）。ページの空白部に配置し、
> 必要なら右クリック→「グループ化」から適用対象を確認する。
> ⚠ **スライダーとオプション指標は同一チャートで併用不可**（機能リファレンス6節）。急上昇語Top15等で
> オプション指標を使いたい場合はスライダーと衝突しないよう設計する。

## デモでの見せ方・トーク例（急上昇 → 時事の物語）

1. **「このページは"今、日本で何がバズっているか"の検知器です」** と切り出す。②の Top15 を見せ、
   1位 `津波 注意 報`(+51,800%)、2位 `最大 震度6強の地震`(+25,650%) を指し **「防災系が上位＝人命に関わる
   検索が最も鋭く跳ねる」** と話す。
2. **時事の物語**: 3位 `FIFA ワールドカップ2026 順位表`(+24,800%)、9位 `大谷 翔平 第二子`、11位
   `ドジャース対オリオールズ` を挙げ **「災害の合間にスポーツ・著名人ニュースが定期的に急上昇する」**
   ＝ ダッシュボードだけで**その時期のニュースアジェンダが読める**と示す。
3. **スライダー実演**: 上昇率スライダーの下限を 5,000 に上げ、**弱い語がスッと消えて"本物のバズ"だけ残る**
   様子をライブで見せる。「閲覧者が自分でバズの閾値を決められる」。
4. **ヒートマップで時間を語る**: ④で期間を直近8週に絞り、`美輪 明宏`(+14,200%, 最新週2026-06-28)など
   **最新週に色が付いた語＝"今まさに来ている話題"** を指す。「行=語、列=週、濃い所がバズ」。
5. **地図の落とし前**: ⑤で全県が同じ濃さになるのを逆手に取り **「津波・W杯は全国同時にバズる＝全国区の
   関心事。逆に地域限定の話題を見たいなら地域比較ページへ」** と P2 に自然に誘導して締める。
