# P3 施設リスト ページ作成手順

前提: [`looker-setup-common.md`](./looker-setup-common.md) 完了。
本ページのデータソースは **`施設明細`（`jp_poi_facilities`）**。

## このページで作るもの
全国8.8万施設をそのまま検索できる「明細画面」。検索ボックス＋フィルタ＋ページング付きテーブルのみの
シンプル構成（15〜20分で終わる）。

### レイアウト図（キャンバス 1366×768）
```
┌──────────────────────────────────────────────────────────────┐
│ [ヘッダー帯] P3 施設リスト                                       │
│ [施設名検索 🔎] [都道府県▼] [自治体▼] [カテゴリ▼]                │
├──────────────────────────────────────────────────────────────┤
│ 表_全国施設一覧（ページング）                                     │
│  name | category | pref_name | muni_name | latitude | longitude │
└──────────────────────────────────────────────────────────────┘
```

## 1. コントロール ×4

| コントロール | 種類 | フィールド | 備考 |
|---|---|---|---|
| 施設名検索 | **入力ボックス** | `name` | **検索タイプを「含む」に変更**（既定は完全一致のため必須）。「小学校」「病院」などで部分一致 |
| 都道府県▼ | プルダウン リスト | `pref_name` | 単一選択 |
| 自治体▼ | プルダウン リスト | `muni_name` | 単一選択 |
| カテゴリ▼ | プルダウン リスト | `category` | 複数選択 |

すべてデータソース = 施設明細。グループ化不要（全部テーブルに効かせる）。

## 2. 表_全国施設一覧

| 項目 | 内容 |
|---|---|
| チャート種類 | 表 |
| ディメンション | `name`, `category`, `pref_name`, `muni_name`, `latitude`, `longitude` |
| 指標 | なし（明細） |
| 並べ替え | `pref_name` → `muni_name` → `category` |
| 設定 | 行数 50／**ページングON** |
| スタイル | `latitude`/`longitude` は小数表示（集計されないことを確認。されていたら共通STEP2参照） |

**期待される表示結果**
- 未フィルタ: 全 **87,745行**（表の下部にページ送りが出る）。
- 施設名検索に「小学校」: 約 **20,687件** に絞られる。
- 「白川町」を自治体▼で選択: 12件（学校8・公民館1・図書館1・病院1・消防署1）。

> ⚠ `latitude`/`longitude` が異常な巨大値になる → 既定集計がSUMのまま。データソース編集で
> 集計「なし」（ディメンション扱い）にするか、表から外す。
> `name` 空欄の行は OSM の名称未登録（数%）。検索デモの邪魔なら
> チャート単位フィルタで `name` IS NOT NULL を追加。

## デモでの見せ方・トークの例
1. 「Excelで管理している施設台帳が、**全国分・検索付き**でここにあります」と開く。
2. 検索ボックスに「体育館」「保育」など自由入力 → 部分一致で出てくる様子を見せる
   （公民館・集会所カテゴリに「〜体育館」等が混ざっているのが分かる）。
3. 「一覧はCSVエクスポートもできるので、**そのまま台帳の初期データ**にもなります」
   （表を右クリック → エクスポート）。
