# P1 施設マップ ページ作成手順

前提: [`looker-setup-common.md`](./looker-setup-common.md)（データソース2本・`latlng`の緯度経度型・カテゴリ7色・3ページ・データ時点表記は設定済み）。
本ページのデータソースは **すべて `施設明細`（`jp_poi_facilities`）に統一**する（コントロール連動のため）。

## このページで作るもの
「自治体を選ぶ → その町の施設が地図に浮かぶ」主役ページ。コントロール3つ＋KPI4枚＋バブルマップ＋横棒2本＋施設一覧。

### レイアウト図（キャンバス 1366×768）
```
┌──────────────────────────────────────────────────────────────┐
│ [ヘッダー帯] 地域施設マップ　　　　　（データ時点: 2021-11）      │
│ [都道府県▼ 岐阜県] [自治体▼ 岐阜市] [カテゴリ▼ すべて]           │
├──────────┬──────────┬──────────┬──────────────┤
│ KPI_施設総数  │ KPI_病院     │ KPI_学校      │ KPI_公民館      │
├──────────┴─────┬────┴──────────┴──────────────┤
│                       │ 棒_カテゴリ内訳（横棒・数値ラベル）        │
│  地図_施設分布          ├───────────────────────────┤
│  （バブル・色=カテゴリ） │ 棒_県内比較（横棒Top10）                │
│                       │  ※自治体▼の適用対象外（グループ化で除外）│
├───────────────┴───────────────────────────┤
│ 表_施設一覧（施設名 | カテゴリ | 自治体）＋クロスフィルタ           │
└──────────────────────────────────────────────────────────────┘
```

## 0. 事前準備
1. タブで **P1 施設マップ** ページを開く。共通ヘッダー帯を設置。
2. グリッドスナップ ON を確認。

---

## 1. コントロール ×3（先に置く。以降のチャートの動作確認に使う）

| コントロール | 種類 | フィールド | データソース | 備考 |
|---|---|---|---|---|
| 都道府県▼ | プルダウン リスト | `pref_name` | 施設明細 | スタイル →「**単一選択**」。既定値は空でよい（全国表示から始まる） |
| 自治体▼ | プルダウン リスト | `muni_name` | 施設明細 | 単一選択。都道府県▼で選択肢が自動で絞られる（同一データソースのため） |
| カテゴリ▼ | プルダウン リスト | `category` | 施設明細 | 複数選択のまま |

**手順**: 「コントロールを追加 → プルダウン リスト」を3つ配置し、上表のとおり設定。ヘッダー帯の下に横一列。

> ⚠ 都道府県▼→自治体▼の連動が効かない場合は、両方のデータソースが `施設明細` になっているか確認
> （片方を集計テーブルにすると連動しない）。

---

## 2. 地図_施設分布（Google マップ・バブル）★このページの主役。最初に解決する

| 項目 | 内容 |
|---|---|
| チャート種類 | **Google マップ（バブルマップ）** |
| データソース | 施設明細 |
| 位置 | `latlng`（緯度経度型にしてあるもの） |
| ツールチップ | `name` |
| **色ディメンション** | `category`（7色固定が効く） |
| サイズ | Record Count（1行=1施設なので同一サイズになる） |
| 配置 | 左中ブロック（幅約600×高さ400） |

**手順**
1. 「グラフを追加 → Google マップ（バブル）」を配置。
2. 位置 = `latlng`。候補に出ない場合はデータソースの型が「緯度、経度」になっているか確認（共通STEP2）。
3. ツールチップ = `name`、**色ディメンション = `category`**、サイズ = Record Count。
4. スタイル → バブルサイズを最小寄りに（全国表示時に潰れないように）。
5. 都道府県▼=岐阜県、自治体▼=岐阜市 にして動作確認。

> ⚠ ハマりどころ:
> 1. **色ディメンションのスロットが見当たらない/効かない** → 「色指標」と排他。色指標側に何か入っていたら外す。
>    どうしても色分けできない場合のフォールバック: 単色バブルにして**カテゴリ▼で絞って見せる**（機能的には成立）。
> 2. **ツールチップが変** → ツールチップは位置と1:1が必要。同一座標に複数施設があると崩れるため、
>    その場合はツールチップを外し「クリック→下の一覧表で見る」（クロスフィルタ）に切り替える。
> 3. 全国表示（コントロール未選択）が重い → 既定で都道府県▼に岐阜県を入れておく運用でもよい。

**期待される表示結果**: 岐阜市で **247施設**。市街地（南部）に密集し、北部山間は疎。
色は 学校（黄土）が最多で、病院（青）・公民館（緑）が市街地に散る。

## 3. KPI スコアカード ×4

| チャート名 | 指標 | チャート単位フィルタ |
|---|---|---|
| KPI_施設総数 | Record Count | なし |
| KPI_病院 | Record Count | `category = 病院` |
| KPI_学校 | Record Count | `category = 学校` |
| KPI_公民館 | Record Count | `category = 公民館・集会所` |

**手順**
1. 「グラフを追加 → スコアカード」を4つ、ヘッダー下に横並び（各 約320×90）。
2. データソース = 施設明細、指標 = Record Count。
3. 2〜4枚目は「設定 → フィルタ → フィルタを追加」で
   「**含める** / `category` / **次に等しい** / 病院」のように作成（学校・公民館も同様）。
4. スタイル → タイトルラベル（「施設総数」「病院」「学校」「公民館・集会所」）。

**期待される表示結果（自治体▼=岐阜市）**: 総数 **247** / 病院 **40** / 学校 **123** / 公民館・集会所 **40**。
（全国＝コントロール未選択なら 総数 87,745 / 病院 10,462 / 学校 45,188 / 公民館・集会所 15,124）

> ⚠ KPIにカテゴリ▼が効くと「カテゴリ=病院」選択時に学校KPIが0になるが、これは正しい動作。
> 気になる場合はKPI4枚をカテゴリ▼のグループに入れない（手順6のグループ化で調整）。

## 4. 棒_カテゴリ内訳（横棒）

| 項目 | 内容 |
|---|---|
| チャート種類 | 横棒グラフ |
| データソース | 施設明細 |
| ディメンション | `category` |
| 指標 | Record Count |
| 並べ替え | Record Count 降順 |
| スタイル | **データラベル ON**（数値表示）／色=ディメンション値（7色固定が効く） |
| 配置 | 右上ブロック（幅約640×高さ180） |

**期待される表示結果（岐阜市）**: 学校 123 → 病院 40 → 公民館・集会所 40 → クリニック 18 → 消防署 17 → 図書館 9。

## 5. 棒_県内比較（横棒）※自治体フィルタの適用対象外にするチャート

| 項目 | 内容 |
|---|---|
| チャート種類 | 横棒グラフ |
| データソース | 施設明細 |
| ディメンション | `muni_name` |
| 指標 | Record Count |
| 並べ替え | Record Count 降順／**行数 10** |
| 配置 | 右下ブロック（幅約640×高さ220） |

**期待される表示結果（都道府県▼=岐阜県）**: 岐阜市 247 / 大垣市 96 / 関市 84 / 高山市 69 /
中津川市 66 / 多治見市 62 / 可児市 57 / 海津市 53 / 郡上市 53 / 各務原市 52。

> ⚠ この時点では自治体▼を選ぶとこのチャートも1本になってしまう。次のグループ化で解決する。

## 6. グループ化（自治体▼の適用範囲を制御）★このページの構築キモ

**目的**: 自治体▼は「地図・KPI・内訳・一覧」だけに効かせ、「県内比較」には効かせない
（比較チャートは常に県内の他自治体と並べたいため）。

**手順**
1. **自治体▼コントロール**と、**地図・KPI×4・棒_カテゴリ内訳・表_施設一覧**（＝比較以外の全チャート）を
   Shift+クリックでまとめて選択。
2. 右クリック → **「グループ化」**（配置メニューからも可）。
3. 動作確認: 自治体▼=岐阜市 → 地図・KPI・内訳・一覧は岐阜市に絞られ、
   **棒_県内比較は岐阜県の10自治体のまま**なら成功。
4. 都道府県▼とカテゴリ▼はグループに**入れない**（ページ全体＝比較チャートにも効かせる）。

> ⚠ グループ化するとまとめて移動されるようになる。位置調整はグループ化の**前**に済ませるか、
> グループ内をダブルクリックで個別選択して動かす。

---

## 7. 表_施設一覧（クロスフィルタ）

| 項目 | 内容 |
|---|---|
| チャート種類 | 表 |
| データソース | 施設明細 |
| ディメンション | `name`, `category`, `muni_name` |
| 指標 | なし（明細表示） |
| 並べ替え | `category` 昇順 → `name` 昇順 |
| 設定 | **クロスフィルタリング ON** ／ 行数 10〜15＋ページング |
| 配置 | 最下段フル幅（幅約1300×高さ170） |

**動作確認**: 地図のバブルをクリック → 表が絞られる（またはその逆）。
`name` が空の行が混ざるのは仕様（OSMの名称未登録。数%）。気になる場合は
チャート単位フィルタで `name` **が NULL でない** を追加。

## デモでの見せ方・トークの例
1. 全国表示から「**全国8.8万施設**が1つの地図に載っています」→ 都道府県▼=岐阜県、自治体▼=白川町。
2. 「**白川町**に絞ると学校8・公民館1…と、**町のインフラが一目で**分かります」（KPI・地図が連動）。
3. 県内比較を指して「岐阜市 247 に対し山間部は数十件。**自治体間の差**がすぐ見えます」。
4. ここで Conversational Analytics に切替え「**白川町で避難所になりそうな施設は？**」と質問 →
   ダッシュボード（見る）とエージェント（聞く）の両輪を見せる。
5. 最後に「データはBQ公式のOpenStreetMap。**2021-11時点**の登録内容で、貴自治体のデータに
   差し替えれば最新化・拡張できます」と締める。
