# 会話分析デモ シナリオ集（OSM 地域施設マップ エージェント）

`jp_facilities_demo` エージェント（Conversational Analytics / Gemini Data Analytics）を
デモで見せるための質問パターン5本。各パターンで**別々の強み**を見せる構成にしてある。
質問文はそのまま貼れば動く。数値は 2026-07-06 に実データ（`ci-ss4-develop.demo_osm_facilities`）で裏取り済み。

> データ時点は 2021-11 スナップショット。件数は「OSMに登録されている数」で実数とは限らない
> （自治体ごとに登録密度差あり）。デモでもこの前提に軽く触れると誠実。

---

## パターン① 曖昧な言葉を用語集で解決する（防災シナリオ）

**見せどころ**: 「避難所」という曖昧語を、エージェントが用語集で
`category IN ('学校','公民館・集会所')` に自動翻訳する。ユーザーはSQLもテーブル名も知らなくていい。

1. `白川町で避難所になりそうな施設を教えて`
   → 学校＋公民館・集会所に解決して一覧。避難場所タグ(全国354件)は使わない挙動を確認。
2. （追撃）`全国だと避難所候補が多い自治体はどこ？Top5で`
   → **横浜市 1,088 / 大阪市 996 / 仙台市 630 / 神戸市 600 / 名古屋市 597**（学校＋公民館の合計）

> トーク: 「"避難所" は元データに無い概念。ビジネス用語をエージェント側の glossary で
> 定義しておくと、現場の言葉のまま質問できる」

---

## パターン② 個票にドリルダウン＋地図で見る（明細テーブル）

**見せどころ**: 集計ではなく「1件ずつの施設」を出す質問。`jp_poi_facilities` を選び、
施設名・緯度経度を返す → 地図描画につながる。

1. `岐阜市の病院を一覧で見せて`
   → **40件**。施設名＋所在。名称は数%欠損する旨も自然に補足されるか確認。
2. （追撃）`それを地図にして`
   → latitude / longitude を使った地図表示。集計質問との使い分けが自動で効く。

> トーク: 「"数を比べて"は集計テーブル、"一覧・地図で"は明細テーブル、と
> エージェントが質問の意図で自動的に投げ先を変える」

---

## パターン③ 自治体どうしを比べる（比較・集計テーブル）

**見せどころ**: 2地点の直接比較。集計済み `dash_muni_category` を選ぶので速い・安い。

1. `高山市と飛騨市で学校の数を比べて`
   → **高山市 46 / 飛騨市 11**。棒グラフで提示されるか確認。
2. （追撃）`その2つ、病院の数だと逆転する？`
   → 会話を引き継いで同じ2市を別カテゴリで再比較（マルチターン文脈保持の実演）。

> トーク: 「隣接自治体の比較は自治体連携・広域防災の定番。前の質問の対象を覚えているので
> "その2つ" で続けられる」

---

## パターン④ 「無い場所」を探す（ネガティブ検索・ランキング）

**見せどころ**: 数の多い所ではなく**欠けている所**を探す、施策につながる問い。

1. `都道府県別の病院数ランキングTop5`
   → **東京都 708 / 大阪府 700 / 愛知県 540 / 福岡県 520 / 神奈川県 481**
2. `岐阜県で図書館がない自治体はどこ？`
   → **10自治体**が該当（図書館の facility_count が0）。「多い所」だけでなく空白地帯を出せる。

> トーク: 「"ある所" は誰でも出せる。"無い所を挙げて"のような穴埋め型の問いに
> 一発で答えられるのが会話分析の強み。行政の資源配分の議論に直結する」

---

## パターン⑤ データの限界を正直に返す（誠実さ＋マルチターン）

**見せどころ**: 答えられない/近似になる質問に、でっち上げず限界を説明する。ハルシネーション対策の実演。

1. `郡上市の小学校だけ見せて`
   → 「小中高はタグで区別できず全て category='学校'。名前で近似します」と**断った上で**
     name に "小学校" を含む **22件**（学校全体は34件）を提示。
2. （追撃）`このデータって最新？`
   → 「2021年11月時点のスナップショットで以後の開閉は未反映」とデータ時点を明示。

> トーク: 「できない事を"できない"と言い、代わりの近似を示す。数字を作らない安全性が
> 業務利用では一番大事。データ鮮度も自分から注記する」

---

## デモの流れ（おすすめ順）

②→③→④ で「一覧 / 比較 / ランキング」の型を見せ、①で用語解決の賢さ、
最後に⑤で誠実さを見せて締める。1本90秒×5で約8分。

質問の投げ方（curl / ステートレス chat）は [`README.md`](./README.md) を参照。
エージェント定義の用語集・golden query は [`jp_facilities_agent.json`](./jp_facilities_agent.json)。
