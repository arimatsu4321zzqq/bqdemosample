# Looker Studio レイアウト案 — 地域施設マップ（osm-facilities）

テーマ＝**自治体で絞る地域の施設マップ**。「自治体を選ぶ → その町の施設が地図に浮かぶ → 隣と比べる」を見せる。
OSMに時系列はないため推移グラフは無し。**分布（地図）・件数（KPI）・比較（棒）・明細（表）**の4部構成。

> Looker Studio 全般の指針は [`../../docs/looker-common.md`](../../docs/looker-common.md)、
> 機能の可否は [`../../docs/looker-studio-capabilities.md`](../../docs/looker-studio-capabilities.md) を参照。
> 本レイアウトの各要素は公式ドキュメントで再現可能なことを確認済み（色ディメンション・ツールチップ・
> コントロールのグループ化・バブル上限100万）。

---

## P1 施設マップ（主役ページ）

```
┌─────────────────────────────────────────────────────────────┐
│ 🏥 地域施設マップ  [都道府県▼岐阜県] [自治体▼岐阜市] [カテゴリ▼] │
│                                     (データ時点: 2021-11 を明記) │
├──────────┬──────────┬──────────┬──────────────┤
│ 施設総数     │ 病院         │ 学校         │ 公民館・集会所   │  ← KPI
├──────────┴──────┬───┴──────────┴──────────────┤
│ 施設分布マップ（バブル）   │ カテゴリ内訳（横棒＋数値ラベル）        │
│  色=カテゴリ              ├───────────────────────────┤
│  ホバー=施設名            │ 近隣自治体と比較（横棒）                │
│                          │  ※自治体ドロップダウンの適用対象外     │
├─────────────────┴───────────────────────────┤
│ 施設一覧テーブル（施設名 | カテゴリ | 自治体 | 緯度経度）             │
└─────────────────────────────────────────────────────────────┘
```

| # | チャート種類 | ディメンション | 指標 | データソース |
|---|---|---|---|---|
| 1 | スコアカード×4 | —（チャート単位フィルタで category を固定） | Record Count | jp_poi_facilities |
| 2 | Google マップ（バブル） | 位置=`latlng`（緯度経度型）/ **色ディメンション=category** / **ツールチップ=name** | サイズ=固定（Record Count） | jp_poi_facilities |
| 3 | 横棒 | category | Record Count（数値ラベル表示） | jp_poi_facilities |
| 4 | 横棒 | muni_name（同一県内・Top10） | SUM(facility_count) | dash_muni_category |
| 5 | テーブル | name, category, muni_name, latlng | — | jp_poi_facilities |
| コントロール | 都道府県▼(pref_name) → 自治体▼(muni_name) → カテゴリ▼(category) | | | |

### 構築の要点
- **コントロールの連動**: 都道府県▼を選ぶと自治体▼の選択肢が絞られる（同一データソースなら自動）。
- **#4 比較チャートだけ自治体フィルタを外す**: 自治体▼と #1〜3,5 を選択して「配置 > グループ化（Ctrl+G）」。
  グループ外の #4 は都道府県▼のみ効く＝「県内の他自治体と比較」になる。
- **ツールチップ（施設名）は位置と1:1が必要**: 同一 latlng に複数施設があると崩れるため、
  ツールチップは name 単独ではなく `CONCAT(name)` 程度に留め、詳細はクロスフィルタ＋テーブルで見せる。
- **データ時点の明記**: テキスト部品で「データ時点: 2021-11（OpenStreetMap スナップショット）」を右上に固定。
- **クロスフィルタ**: テーブル行クリック→マップ絞り込みをオンにする。
- スキャン量: jp_poi_facilities は 8.8万行・十数MBのため直結で問題なし（Extract 不要）。

## P2 自治体比較

| # | チャート | ディメンション | 指標 |
|---|---|---|---|
| 1 | 横棒（Top20） | muni_name | SUM(facility_count)（カテゴリ▼で切替） |
| 2 | ピボット表＋ヒートマップ | 行=muni_name × 列=category | facility_count |
| 3 | スコアカード | — | 県内自治体数 / 県内施設総数 |

- データソースは dash_muni_category（約7,600行）。都道府県▼で県内比較、外せば全国ランキング。
- 「人口1万人あたり」に拡張する場合は自治体人口テーブルを追加読み込みして計算フィールド化（将来）。

## P3 施設リスト

| # | チャート | 内容 |
|---|---|---|
| 1 | 入力ボックス | 施設名の部分一致検索（例: 「小学校」） |
| 2 | テーブル（ページング） | name / category / pref_name / muni_name / latitude / longitude |

- 全国8.8万行をそのまま。行数制限＋ページングで軽快に動く。

## ページ共通

- ページタブ: P1 施設マップ / P2 自治体比較 / P3 施設リスト（上タブナビ）
- テーマ: カスタムテーマで配色統一（「自社プロダクト感」。docs/looker-common.md 参照）
- 各ページに「AIに質問」導線（Conversational Analytics エージェント `jp_facilities_demo` のデモと一体で見せる）
- カテゴリの色は7色固定（病院/クリニック/学校/公民館・集会所/図書館/消防署/避難場所）。
  フィルタで系列数が変わっても色が変わらないよう、スタイルでディメンション値ごとに色を固定する
