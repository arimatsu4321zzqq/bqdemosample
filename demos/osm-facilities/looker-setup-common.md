# Looker Studio ダッシュボード共通セットアップ手順（P1〜P3 共通の土台）

「地域施設マップ ダッシュボード」を手動構築するための**最初に1回だけ行う共通設定**。
各ページ手順書（`looker-page-P1〜P3`）はこのファイルを前提にする。機能の詳細・再現可否の根拠は
[`looker-studio-capabilities.md`](../../docs/looker-studio-capabilities.md) を参照。

- 対象プロジェクト: `ci-ss4-develop` / データセット: `demo_osm_facilities`（ロケーション **US**）
- 使うテーブル（[`sql/create_osm_facilities_demo.sql`](./sql/create_osm_facilities_demo.sql) で作成済み）:
  - `jp_poi_facilities` … 施設明細（8.8万行）。マップ・KPI・一覧。
  - `dash_muni_category` … 自治体×カテゴリ集計（約7,600行）。比較・ランキング。
- google-trends と違い**時間軸が無い**（2021-11のスナップショット）。期間コントロールは使わない。

---

## STEP 0. レポート作成
1. https://lookerstudio.google.com → 「空のレポート」を作成。
2. レポート名を **「地域施設マップ ダッシュボード」** に変更。

## STEP 1. データソースを2本追加（テーブル選択方式）
「リソース → 追加済みのデータソースの管理 → データを追加 → BigQuery」から、以下を**2回**繰り返す。
1. 認証 → プロジェクト `ci-ss4-develop` → データセット `demo_osm_facilities` → テーブル選択。
2. 対象テーブル: `jp_poi_facilities` / `dash_muni_category`。
3. 各データソースの名前を分かりやすく: **`施設明細`** / **`自治体×カテゴリ集計`**。

> テーブル選択方式でよい（カスタムクエリ不要）。8.8万行・十数MBなので Extract も不要。

## STEP 2. フィールドの型・既定集計を設定（★最重要）

### 施設明細（jp_poi_facilities）
| フィールド | 設定する型 | 備考 |
|---|---|---|
| `latlng` | **地域 → 緯度、経度** | **マップはこれを使う**。"35.42,136.76" 形式の文字列 |
| `name` / `category` / `muni_name` / `pref_name` / `amenity` | テキスト | そのまま |
| `latitude` / `longitude` | 数値（集計 **なし/平均**） | 表の表示用。SUMのままだと表で合計されて壊れる |
| `is_assembly_point` | 真偽値 | そのまま |
| Record Count | （自動生成の指標） | **件数は常にこれを使う**（1行=1施設） |

### 自治体×カテゴリ集計（dash_muni_category）
| フィールド | 既定の集計 | 備考 |
|---|---|---|
| `facility_count` | **合計 (SUM)** | 既定のままで正しい（自治体を束ねると足し算になる） |
| `named_count` | 合計 (SUM) | 参考値 |

> google-trends と違い「AVGに直す」作業はほぼ無い。唯一の罠は `latitude`/`longitude` の SUM と、
> `latlng` の型を**「緯度、経度」にし忘れる**こと（テキストのままだとマップの位置に指定できない）。

## STEP 3. テーマ・キャンバス・カテゴリ色（全ページ共通の見た目）
- 「テーマとレイアウト → テーマ」でカスタムテーマを作成。
  - 背景 `#FFFFFF` / パネル `#F8FAFC` / 文字 `#0F172A` / アクセント `#2563EB`
- **カテゴリ7色を固定**（フィルタで系列数が変わっても色が変わらないように。
  「リソース → ディメンション値の色の管理」で category の値ごとに割当てるのが確実）:

| category | 色 |
|---|---|
| 病院 | `#2A78D6`（青） |
| クリニック | `#1BAF7A`（青緑） |
| 学校 | `#EDA100`（黄土） |
| 公民館・集会所 | `#008300`（緑） |
| 図書館 | `#4A3AA7`（紫） |
| 消防署 | `#E34948`（赤） |
| 避難場所 | `#E87BA4`（桃） |

- **キャンバスサイズ**: 幅 1366 × 高さ 768（「テーマとレイアウト → レイアウト」）。
- チャートヘッダー:「ホバー時に表示」。グリッドスナップ ON。

## STEP 4. ページ構成とナビゲーション
1. ページを3枚用意し、名前を設定: **P1 施設マップ** / **P2 自治体比較** / **P3 施設リスト**。
2. 「テーマとレイアウト → レイアウト → ナビゲーションタイプ」= **タブ**（または左）。
3. 各ページ上部に共通ヘッダー帯（長方形＋タイトルテキスト）。P1で作って全ページへコピペ。

## STEP 5. レポートレベルの共通部品
- **データ時点の明示（必須）**: テキスト部品で
  **「データ時点: 2021-11（OpenStreetMap スナップショット）」** をヘッダー右上に置き、
  右クリック → 「レポートレベルにする」で全ページ表示に。
- OSMは有志作成データのため、フッターに小さく
  「出典: © OpenStreetMap contributors（ODbL）/ 登録密度は自治体により差があります」を置く。

## 命名・ファイル規約
- 各ページ手順書: `looker-page-P1-map.md` / `-P2-compare.md` / `-P3-list.md`（本フォルダ内）
- チャート名の例: 「地図_施設分布」「KPI_施設総数」「棒_県内比較」。

---

## 補足: このダッシュボード固有の設計ルール
1. **P1のチャートは原則すべて `施設明細` に統一**する（コントロールはデータソース単位で効くため、
   混ぜると連動しない部品ができる）。集計テーブルは P2 で使う。
2. **コントロールの適用範囲はグループ化で制御**する（自治体▼を「県内比較」チャートに効かせない等。
   選択して右クリック → グループ化。詳細は P1 手順書）。
3. 色は category のディメンション値で固定（STEP 3）。順位や件数で塗り替えない。
