# P2 自治体比較 ページ作成手順

前提: [`looker-setup-common.md`](./looker-setup-common.md) 完了、P1構築済み。
本ページのデータソースは **`自治体×カテゴリ集計`（`dash_muni_category`）に統一**（P1とは別）。

## このページで作るもの
自治体を横並びで比べる「ランキング画面」。都道府県で絞れば県内比較、外せば全国ランキング。
横棒Top20＋ピボット表（ヒートマップ）＋KPI2枚＋コントロール2つ。

### レイアウト図（キャンバス 1366×768）
```
┌──────────────────────────────────────────────────────────────┐
│ [ヘッダー帯] P2 自治体比較   [都道府県▼] [カテゴリ▼]             │
├──────────────┬──────────────────────────────────┤
│ KPI_対象自治体数   │ KPI_施設総数                            │
├──────────────┴────────┬─────────────────────────┤
│ 棒_自治体ランキングTop20      │ ピボット_自治体×カテゴリ           │
│ （横棒・SUM(facility_count)） │ （ヒートマップ書式）                │
└──────────────────────┴──────────────────────────┘
```

---

## 1. コントロール ×2

| コントロール | 種類 | フィールド | データソース |
|---|---|---|---|
| 都道府県▼ | プルダウン リスト（単一選択） | `pref_name` | 自治体×カテゴリ集計 |
| カテゴリ▼ | プルダウン リスト（複数選択） | `category` | 自治体×カテゴリ集計 |

> ⚠ P1のコントロールとは**別物**（データソースが違うため、P1のものをコピーしても効かない）。
> このページ用に新規で置く。グループ化は不要（ページ内全チャートに効かせてよい）。

## 2. KPI スコアカード ×2

| チャート名 | 指標 | 設定 |
|---|---|---|
| KPI_対象自治体数 | `muni_name` | 集計を **COUNT_DISTINCT（個別カウント）** に変更 |
| KPI_施設総数 | `facility_count` | SUM のまま |

**期待される表示結果**: 全国（未選択）で 自治体数 **1,684** / 施設総数 **87,745**。
都道府県▼=岐阜県で 自治体数 **42** / 施設総数 **1,452**。

## 3. 棒_自治体ランキングTop20（横棒）

| 項目 | 内容 |
|---|---|
| ディメンション | `muni_name` |
| 指標 | `facility_count`（SUM） |
| 並べ替え | `facility_count` 降順／**行数 20** |
| スタイル | 単色アクセント `#2563EB`。データラベル ON |

**期待される表示結果（全国）**: 大阪市 1,734 / 横浜市 1,514 / 仙台市 1,335 / 神戸市 990 / 名古屋市 888 …
カテゴリ▼=病院に絞ると病院数ランキングに切り替わる。

> ⚠ この順位は「OSMに登録された施設数」であり人口順ではない（仙台市が3位に来るのは
> 東北のマッピング活動が活発なため）。デモでは**登録密度の差ごと説明**すると誠実
> （データ時点・出典の注記が効いてくる場面）。

## 4. ピボット_自治体×カテゴリ（ヒートマップ）

| 項目 | 内容 |
|---|---|
| チャート種類 | **ピボット表（ヒートマップ付き）**（チャート選択時にバリエーションで選ぶ） |
| 行ディメンション | `muni_name` |
| 列ディメンション | `category` |
| 指標 | `facility_count`（SUM） |
| 並べ替え | 行を `facility_count` 降順／行数 15〜20 |

ヒートマップ書式が選べない場合は通常のピボット表＋「スタイル → 指標の表示 = ヒートマップ」で同等。

**期待される表示結果（都道府県▼=岐阜県）**: 行=岐阜市(学校123, 病院40, 公民館40…)、大垣市、関市…と
市部が上に並び、色の濃淡で「どの自治体がどの施設に厚いか」が読める。

---

## デモでの見せ方・トークの例
1. 全国Top20で「政令市が上位。ただし**これはOSMの登録数**で、地図データの充実度も同時に見えています」。
2. 都道府県▼=岐阜県 → 「県内では岐阜市が突出、山間部の町村は1桁〜数十件」。
3. カテゴリ▼=公民館・集会所 → 「**防災の受け皿**がどの自治体に多いかが即座に出ます」。
4. ピボットを指して「自治体×施設種の一覧表は、**紙の資料で毎回作っているもの**がリアルタイムに出る、と刺さりやすい」。
