# ソリューション概要：BigQuery × AI会話分析 × Looker Studio

本資料は、提案資料を作成するための一次情報としてまとめたものである。事実（一次資料に基づくもの）と推測（商談ヒアリング・仮説）を区別して記載する。

---

## 1. 概要

本ソリューションは、BigQuery（データ基盤）、AI会話型分析（Conversational Analytics）、Looker Studio（ダッシュボード）の3点で構成するデータ活用環境である。SQL や BI の専門知識を必要とせず、日本語による問い合わせでデータの可視化・分析が可能であり、かつ無償で関係者と共有できる点を特徴とする。

- 主たる対象は、地域データを扱う自治体・地域企業である。副次的に、Excel・手作業・アンケート等で社内データが分散している一般企業を対象とする。
- 社内で「DataStudio」と呼称しているものは、このうち Looker Studio（旧 Google データポータル）を指す。単体ではなく3点セットとして提示する。

---

## 2. 経緯

発端は、白川村（白川郷）の観光ダッシュボード（Microsoft Power BI・全15ページ）である。観光客の動向把握には NTTドコモの人流データ（モバイル空間統計）を用いていたが、Power BI の無償プランでは外部共有・閲覧者数に制限があり、関係者へ配布できないという課題があった。また、地図表現に用いていたバブルマップに「廃止予定」の警告が表示される等、機能面の懸念もあった。

これらの課題に対し、共有が容易な Looker Studio への移行を起点とし、BigQuery と AI会話分析を加えて「閲覧」から「対話的な分析」へ発展させ、公開データを用いて汎用的なデモとして再構成したものが本ソリューションである。

なお、この白川村案件は代表例の一つにすぎない。本ソリューションの対象は、既存 BI（Power BI 等）の移行に限らず、手作業（アナログ）による集計・資料、地域データ、アンケート等、共有・活用されずに閉じているデータ全般である。

### 取り込める元データの例

| 元の形 | 例 | 移行後にできること |
|---|---|---|
| 既存BIダッシュボード | Power BI 等 | 無償でURL共有・埋め込み／AI会話分析を追加 |
| 手作業（アナログ）の集計・資料 | Excel・紙で毎月まとめている統計 | 自動集計・共有・日本語による問い合わせ |
| 地域データ | 人口・施設・観光・行政の公開/保有データ | 横断分析・地図可視化・穴埋め型の問い |
| アンケートデータ | 満足度・利用実態調査 等 | 傾向の可視化・要因分析・次アクションの提示 |

### デモ環境のテーマ

「ある地域（自治体）で絞り込み、その地域の傾向・特徴を提示する」ことをテーマとする。県・自治体を選択すると、当該地域の施設分布や検索トレンドが連動して表示される構成であり（全国施設マップ／検索トレンドの2件）、「自地域を選択すると、その地域のことが分かる」体験を軸とする。

## 3. 提供価値

分散したデータ（既存BI・手作業/アナログ・地域データ・アンケート等）を取り込み、業種・データを問わず再現できる3つの価値を確立した。

- **共有**：Looker Studio により、無償でのURL共有・Web埋め込みが可能であり、閲覧者数の制限がない。ツールに閉じていたデータを関係者へ配布できる。
- **分析**：AI会話型分析により、SQL 不要・日本語での問い合わせで、現状把握・要因分析・将来予測・施策提案までを一貫して行える（予測は精度を保証するものではなく、傾向把握の補助である。第5章参照）。
- **アクセス制御**：特定の AIエージェント・データセットのみを顧客アカウントへ開放する IAM 設計を持つ。外部相当のアカウントで疎通を確認済みである。

以上を、顧客データに依存しない汎用デモとして実装済みである（全国 約8.8万施設マップ／検索トレンドの2件）。いずれの案件においても同一の形で提示できる。

裏付けとして、発端の個別案件（Power BI・全15ページ）についても実機で再現検証を行い、再現困難 0 件（完全再現、および一部は代替表現により全ページ対応）を確認した。実データによる数値の裏取り、および「数値を作らず、限界を正直に返す」設計も標準仕様に組み込んでいる。

### 顧客評価（商談ヒアリングに基づく）

- 無償でURL共有ができ、関係者に配布できる点（Power BI における最大の不満点の解消）。
- 会話分析が現状分析にとどまらず、将来予測・施策提案まで出力できる点。

## 4. 特長と費用

### 特長

| 項目 | 内容 |
|---|---|
| 費用 | Looker Studio・AIエージェントはそれ自体無償。課金は BigQuery のデータ保管・クエリ実行のみで、中小規模では実質的に無償の範囲に収まり得る |
| 共有 | 無償でURL共有・Web埋め込み・閲覧者数無制限（Power BI 無償プランは外部共有が有償） |
| 分析 | SQL 不要。日本語で現状把握から要因分析・将来予測・施策提案まで一貫 |
| 将来性 | Google サービス（BigQuery / Sheets）と親和。廃止予定機能を回避 |
| 実証性 | 発端の個別案件で全ページを実機再現。汎用デモにより同一の形で提示可能 |

### 費用

Looker Studio および AIエージェントは、それ自体に費用は発生しない。課金対象は BigQuery のデータ保管とクエリ実行のみであり、いずれにも無償枠が設定されている。

| 項目 | 料金 | 無償枠 |
|---|---|---|
| Looker Studio（無料版） | 無料 | — |
| AIエージェント（会話分析 / Data Agent） | 無料 | — |
| BigQuery クエリ実行（オンデマンド） | $6.25 / TB | 月1TB まで無料 |
| BigQuery ストレージ | $0.02 / GB / 月 | 月10GB まで無料 |
| （必要な場合のみ）Looker Studio Pro | $9 / ユーザー / 月 | 30日無料トライアル |

- 中小規模では実質的に無償の範囲に収まり得る（例：約10万件・数十MB は、ストレージ無償枠の 0.1% 未満）。
- 留意点：Looker Studio は表示のたびに BigQuery へクエリを発行し、月1TB の無償枠を消費する。大規模データを高頻度で閲覧する場合は課金が発生し得る（対策：集計テーブル化・BI Engine・請求アラート）。規模に応じて無償となるものであり、常に無償ではない。

## 5. 制約・留意事項

- 将来予測は精度を保証するものではなく、データの量・質に依存する傾向把握の補助である。確実な的中を前提とした提示は行わない。
- 会話分析の出力を、レポートへ直接自動連携することはできない（生成ロジックを取り出し、ダッシュボードに実装する運用となる）。
- 会話分析の CSV 一括ダウンロードは非対応である（コピーによる取得で対応）。
- Looker Studio：積み上げ棒グラフとスクロールの同時使用は不可、階層ドリルダウンは非対応である（2段ドロップダウンで代替）。
- デモの数値は例示である（公開データに基づく。施設マップは2021年11月時点のスナップショット、検索トレンドの score は相対値であり単純比較はできない）。
