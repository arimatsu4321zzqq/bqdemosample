# 提案パッケージ — 概要と構成

本フォルダは、BigQuery・AI会話分析・Looker Studio によるデータ活用ソリューションの提案パッケージである。一般公開データを用いて構成しており、顧客データは含まない。ダッシュボードの閲覧、実データへのアクセス、および定義一式（テーブル・データ・AIエージェント）の確認が、本フォルダ内で完結する。

---

## 位置づけ

- 無償で共有できるダッシュボード（Looker Studio）と、日本語で問い合わせ可能な AI分析（Conversational Analytics）を、公開データで再現した汎用デモである。
- 各案件へ同一の形で提示する提案資料であると同時に、顧客への標準納品物のサンプルでもある。

## 構成

| 資料 | 内容 |
|---|---|
| `briefing.md` | ソリューション概要（経緯・提供価値・費用・制約）。最初に参照する。 |
| `osm_facilities/` | デモ① 地域施設マップ（画面・限定公開URL・仕様書） |
| `google_trends/` | デモ② 検索トレンド（準備中） |

各デモのフォルダは、次の3点で構成する。

| ファイル | 内容 |
|---|---|
| `dashboard.pdf` | ダッシュボードの画面 |
| `dashboard-link.md` | ダッシュボードの限定公開URL |
| `appendix_spec.md` | 仕様書（テーブル定義・データ定義・AIエージェント定義） |

## デモ①（地域施設マップ）

- 限定公開URL：https://datastudio.google.com/reporting/3e8bbacd-785f-466e-b9f3-806fc4b9dbed
- 県・自治体を選択すると、当該地域の施設が地図・比較・一覧で連動して表示される（全国 約8.8万施設）。
- 「〇〇市で避難所になり得る施設は」といった日本語での問い合わせにも対応する。

## 留意事項

- ダッシュボードのデータ時点は 2021年11月（公開データのスナップショット）である。実導入時は最新データに差し替える。
- URL は限定公開である。本フォルダを第三者へ提供する際は、共有範囲に留意すること。
